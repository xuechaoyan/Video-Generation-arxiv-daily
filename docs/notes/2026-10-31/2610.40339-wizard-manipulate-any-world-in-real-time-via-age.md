# Wizard: Manipulate Any World in Real Time via Agentic Control

- **日期**：2026-10-31
- **评分**：77/100
- **作者**：Yuzhe Wu, Zijun Lin, Yeying Jin
- **方向**：Video Generation, World Models
- **论文**：[arXiv 2610.40339](http://arxiv.org/abs/2610.40339v1)
- **代码**：未开源

## Abstract 中文翻译

近年来，视频世界模型的发展使得生成越来越逼真且具有交互性的虚拟环境成为可能，为玩家可定制的游戏玩法开辟了新的可能性。智能体框架进一步推动了这一方向的发展，将显式游戏逻辑和可控世界表示与视觉生成解耦。然而，现有方法仅支持简单的游戏设置和预定义的运动模式，对未见过的环境和角色泛化能力较差，并且实时交互能力有限。本文提出Wizard，一种智能体游戏世界模型，能够实时、精确地控制角色运动，并对全新的场景、角色和动作实现零样本泛化。为此，我们构建了一个涵盖750个场景和178个角色的多样化数据集，并将骨骼和几何信息纳入结构化表示。我们利用这些表示作为中间代理来条件化视频生成模型，同时引入自适应掩码机制，以改善条件信号与生成视频展开之间的对齐。此外，我们提出一种智能体框架，能够显式维护和更新游戏状态，使玩家可以自由配置虚拟世界，并对角色运动进行细粒度控制，同时保持视觉质量和游戏玩法的一致性。通过将智能体控制与基于结构化代理的生成相结合，我们的框架为玩家驱动的游戏创作提供了新的可能性，实现了实时、可泛化且机械机制一致的世界模拟。

## 全文总结

Wizard将智能体世界状态管理、场景几何代理、角色关节骨骼控制与视频生成结合起来。系统从用户提供的场景和角色图像重建可编辑几何、角色网格及骨骼，并通过动作检索和重定向生成适配的动作库；智能体根据玩家输入和战斗状态更新场景、角色动作、生命值、距离及技能冷却等状态，再由视频模型渲染连续画面。模型使用覆盖750个场景和178个角色的50.3小时代理—视频数据训练，引入角色感知的自适应注意力掩码，并通过因果适配和少步蒸馏实现基于KV缓存的流式生成，在2步去噪下达到24 FPS。实验以定性结果为主，展示了对未见场景、角色和动作的零样本泛化，以及角色变换、场景操控和机制一致的战斗交互。

## 核心贡献

1. 提出Wizard智能体游戏世界模型，将细粒度角色骨骼控制、场景几何控制、显式游戏状态管理和视频生成结合，实现实时、零样本且机制一致的交互式世界模拟。2. 构建涵盖750个场景、178个角色和50.3小时对齐代理—视频数据的数据集，统一编码场景几何与角色骨骼。3. 提出基于结构化代理的智能体视频到视频框架，支持角色动画、场景编辑、战斗规划和规则执行。4. 利用骨骼提供的角色位置构造角色感知的自适应注意力掩码，将参考图像与对应角色区域绑定，改善角色身份保持和参考图像—生成视频对齐。5. 采用因果适配、少步蒸馏和有限窗口KV缓存，实现24 FPS、2步去噪的自回归实时生成。

## 与课题的关系

该工作与研究重点高度相关：它是面向游戏的动作条件视频世界模型，通过玩家输入驱动角色动作、相机和场景几何，并由显式世界状态和规则控制器形成闭环交互。其结构化场景代理和关节骨骼代理为可控视频扩散提供中间条件，适用于动作条件视觉世界模型和闭环模拟。因果适配、自回归生成、20个近期潜变量帧加持久汇聚帧的KV缓存、2步蒸馏以及24 FPS运行直接涉及流式、长视频、实时生成、稀疏时空上下文和缓存复用方向。其零样本场景、角色和动作泛化也与可扩展的交互式视频生成密切相关。

## 局限 / 待核实

论文明确指出两项限制：第一，系统依赖动作库，对于具有罕见身体结构的角色，难以找到兼容动作；第二，在更长的视频展开过程中，场景代理与生成视频之间的一致性可能下降。论文还说明其当前实验主要采用定性评估，未明确报告与基线的系统定量比较。
