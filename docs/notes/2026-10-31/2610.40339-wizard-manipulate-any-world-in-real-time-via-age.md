# Wizard: Manipulate Any World in Real Time via Agentic Control

- **日期**：2026-10-31
- **评分**：77/100
- **作者**：Yuzhe Wu, Zijun Lin, Yeying Jin
- **方向**：Video Generation, World Models
- **论文**：[arXiv 2610.40339](http://arxiv.org/abs/2610.40339v1)
- **代码**：未开源

## Abstract 中文翻译

近年来，视频世界模型的发展使生成更加逼真且具有交互性的虚拟环境成为可能，为玩家可定制的游戏体验开辟了新的空间。智能体框架进一步推动了这一方向，通过将显式游戏逻辑和可控世界表示与视觉生成解耦，提升了系统能力。然而，现有方法仅支持简单的游戏设定和预定义的运动模式，对未见过的环境和角色泛化能力较弱，实时交互能力也有限。本文提出 Wizard，一种智能体游戏世界模型，能够实时、精确地控制角色运动，并以零样本方式泛化到新场景、新角色和新动作。为此，我们构建了一个涵盖 750 个场景和 178 个角色的多样化数据集，并将骨骼与几何信息作为结构化表示。我们利用这些表示作为中间代理来条件化视频生成模型，同时引入自适应掩码机制，以改善条件信号与生成视频轨迹之间的对齐。此外，我们提出一种智能体框架，能够显式维护和更新游戏状态，使玩家可以自由配置虚拟世界，并对角色运动进行细粒度控制，同时保持视觉质量和游戏玩法的一致性。通过结合智能体控制与基于结构化代理的生成，该框架为玩家驱动的游戏创作解锁了新的可能性，实现了实时、可泛化且机械机制一致的世界模拟。

## 全文总结

Wizard 是一个面向可定制游戏世界的智能体视频世界模型。系统从用户提供的场景图像和角色图像中重建近似场景几何、角色网格与骨骼，并通过运动检索和重定向生成可控动作。智能体显式维护角色姿态、位置、生命值、攻击阶段和冷却时间等状态，以实现规则一致的战斗控制；视频模型则根据场景几何、角色骨骼、外观参考和历史帧生成视觉结果。作者构建了包含 50.3 小时数据、750 个场景和 178 个角色的数据集，引入角色感知自适应注意力掩码，并通过因果适配、蒸馏和 KV 缓存实现 24 FPS、两步去噪的实时自回归生成。实验展示了对未见场景、角色和动作的零样本泛化，以及角色变换、场景操纵和机制一致的开放式游戏交互。

## 核心贡献

1. 提出 Wizard 智能体游戏世界模型，将场景几何控制、角色关节骨骼控制、显式游戏状态管理和视频生成结合起来，实现实时、细粒度且机制一致的交互式世界模拟。 2. 构建涵盖 750 个场景、178 个角色和 50.3 小时对齐代理—视频数据的数据集，统一编码场景几何与角色骨骼，以增强跨场景、跨角色和跨动作泛化能力。 3. 提出基于结构化视觉代理的视频到视频生成框架，通过角色骨骼和几何代理控制摄像机、场景与角色动作，并支持新角色的动作检索和重定向。 4. 提出角色感知自适应注意力掩码，根据骨骼位置将角色参考图像绑定到对应区域，减少角色间外观泄漏并提升身份保持与条件对齐。 5. 采用因果适配、少步一致性蒸馏和分布匹配蒸馏，并结合有限窗口 KV 缓存，实现 24 FPS、两步去噪的实时流式生成。

## 与课题的关系

该工作与研究重点高度相关。它属于视频世界模型和视频扩散生成范畴，将玩家输入转化为结构化场景几何、角色骨骼和显式游戏状态，再由视频生成模型进行闭环视觉渲染。其智能体框架支持动作条件控制、状态跟踪、规则执行和战斗行为规划，直接涉及动作条件视觉世界模型与闭环模拟。模型采用因果适配、自回归滑动窗口、KV 缓存和少步蒸馏，针对长时、流式及实时生成问题进行优化，并达到 24 FPS。结构化代理和角色感知注意力掩码也体现了对空间控制、稀疏条件关联和跨角色信息隔离的探索。

## 局限 / 待核实

论文明确指出两项限制：第一，系统依赖动作库，对于具有罕见身体结构的角色，可能难以找到兼容的动作；第二，在更长的视频生成轨迹中，场景代理与生成视频之间的一致性可能下降。此外，论文未报告系统性的定量对比或大规模用户评测，且初始化阶段需要少于五分钟进行场景重建、角色绑定和动作集构建。
