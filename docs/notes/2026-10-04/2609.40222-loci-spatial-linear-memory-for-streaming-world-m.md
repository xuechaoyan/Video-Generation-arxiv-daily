# LOCI: Spatial Linear Memory for Streaming World Models

## Abstract 中文翻译

当摄像机重新访问此前观察过的区域时，视频世界模型应当再现那里原有的内容。这既要求记住过去的观测，也要求针对当前视角检索正确的观测。键值缓存能够保留视觉细节，但会随视频长度增长；循环记忆较为紧凑，却会把历史压缩到固定大小的状态中，使单个过去观测不再能够被直接访问。我们提出 LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的 Transformer 模块中，主注意力维护过去观测的键值缓存；在另一半模块中，主注意力被限制在当前块内，并结合一种循环线性注意力记忆，其读写由投影摄像机几何条件化，因此视角同时参与记忆寻址和存储内容的形成。循环读出结果会流入后续由缓存支持的模块，并为这些模块的查询提供累积的场景上下文。在公开的 MIND 记忆基准和留出的已记录轨迹上，与具有代表性的世界模型以及采用相同训练方案的全 Softmax 模型相比，LOCI 能够更忠实地再现重新访问的内容；在使用完整历史时，在相同长度下其峰值内存比全 Softmax 低约 30%。在采用有界的保留观测库时，LOCI 能够以恒定内存生成长视频，并且在相同内存预算下比全 Softmax 更加忠实。

## 全文总结

本文研究摄像机控制视频世界模型在长时间离开后重新访问场景时的空间记忆问题。LOCI 将两种记忆结合起来：一方面，在部分 Transformer 层中保留历史观测的显式键值缓存，以直接访问视觉细节；另一方面，使用由摄像机投影几何条件化的循环线性注意力状态，压缩保存完整历史并帮助后续查询定位相关观测。模型采用块级因果生成、块级遗忘和可选的有界观测库，从而支持完整历史访问和恒定内存的长视频流式生成。实验基于 MIND、Unreal Engine 留出轨迹及其他记录视频，结果显示 LOCI 在场景重访保真度方面优于代表性模型和同配方全 Softmax 基线；在相同有界 KV 预算下，MIND 全片段 PSNR 提升 0.89 dB，并可在有界模式下以恒定内存生成 300 秒视频。

## 核心贡献

1. 提出混合空间记忆架构，将由投影摄像机几何条件化的循环记忆与显式历史 KV 访问结合，使循环上下文能够影响历史注意力查询，同时保留观测级视觉细节。循环记忆采用逐 token 的增量更新，并将通道保留操作改为每个视频块执行一次，使遗忘频率对应经过的视频时间而非 token 排列。 2. 将贯穿完整历史的固定大小循环状态与固定容量的历史观测库结合，实现有界内存的流式生成。在相同的有界 KV 预算下，相比同样训练方案的全 Softmax 模型，LOCI 在 MIND 记忆测试上对全部 50 个片段取得更好的结果，整段 PSNR 提升 0.89 dB，且生成 300 秒视频时内存保持恒定。 3. 在公开 MIND 基准上，LOCI 零样本取得低于 GIM-World 的 MSE 以及更高的 PSNR 和 SSIM；在短时和长时场景重访中，相比全 Softmax 及多个外部世界模型表现出更好的局部和整体一致性。 4. 通过消融和分析实验表明，循环状态能够编码摄像机方向，并通过读出结果引导后续历史注意力集中于与当前视角共可见的内容；在完整历史模式下，LOCI 将可达生成长度从 157 秒延长至 225 秒，并在相同长度下降低约 30% 的内存占用。

## 与课题的关系

LOCI 与研究重点直接相关。它是面向摄像机动作和轨迹控制的视频世界模型，目标是在闭环式空间探索中保持场景结构和外观的一致性，尤其解决摄像机离开后重新回到原地点时的内容恢复问题。其块因果生成方式适合自回归、流式和长视频生成；循环线性注意力提供固定大小的历史状态，显式 KV 缓存和有界观测库则保留可检索的视觉细节。通过将 PRoPE 摄像机几何编码用于循环记忆的读写，模型实现了动作/视角条件下的空间寻址。用循环状态替换一半历史主注意力 KV 后，模型降低了内存增长，并在有界模式下实现恒定内存的长视频生成，体现了稀疏历史访问、缓存复用和记忆压缩方面的设计。论文没有提出扩散蒸馏或专门的实时低延迟采样方法，但报告了在有界稀疏模式下与全 Softmax 相同的速度，以及更低的内存占用。

## 局限 / 待核实

论文明确说明：留出的轨迹主要由 Unreal Engine 渲染，未评估真实世界采集的视频；所有模型的绝对保真度仍然较低，基准平均 PSNR 低于 15 dB，因此结果主要应理解为相对改进；实验只使用一个 5B 主干和较短的 5,000 步微调预算；逐 token 保留机制的比较依赖于短期比较之后定义的扩展指标；所有模型在 30 个模块中都保留了显式历史摄像机注意力分支，因此循环路径只减少了一半主注意力 KV，而不是全部历史存储；训练时循环状态由带噪块特征构建，而推理时则由生成块提交，二者存在差异；有界稀疏模式下与全 Softmax 的速度相当依赖于论文中的优化实现。此外，论文未明确说明 LOCI 在更大规模模型、更多真实场景、不同摄像机控制任务或更长训练预算下的表现。
