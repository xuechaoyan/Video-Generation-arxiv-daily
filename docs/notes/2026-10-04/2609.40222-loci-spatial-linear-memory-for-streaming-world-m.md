# LOCI: Spatial Linear Memory for Streaming World Models

- **方向**：World Models

## Abstract 中文翻译

当摄像机重新访问此前观察过的区域时，视频世界模型应当重现那里原有的内容。这既要求记住过去的观测，也要求针对当前视点检索正确的观测。键值缓存能够保留视觉细节，但会随着视频长度增长；循环记忆虽然紧凑，却会将历史压缩为固定大小的状态，使单个过去观测不再能够被直接访问。我们提出 LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的 Transformer 模块中，主注意力保留过去观测的键值缓存；在另一半模块中，主注意力被限制在当前块，并结合循环线性注意力记忆，其读写由投影相机几何条件化，使视点同时参与记忆寻址和存储内容的形成。循环读出结果会传递到后续依赖缓存的模块，并为这些模块的查询提供累积的场景上下文。在公开的 MIND 记忆基准和留出的录制轨迹上，LOCI 比具有代表性的世界模型以及采用相同训练方案的全 Softmax 模型更忠实地重现被重新访问的内容；在使用完整历史时，在相同长度下，其峰值内存相较全 Softmax 降低约 30%。在使用有界的保留观测库时，它能够以恒定内存流式生成长视频，并且在相同内存预算下仍比全 Softmax 更加忠实。

## 全文总结

论文针对摄像机控制视频世界模型在长时间间隔后返回旧场景时的空间一致性问题，提出 LOCI 混合空间记忆架构。LOCI 在 30 个 Transformer 模块中交替使用保留历史 KV 的 Softmax 注意力，以及结合 Kimi Delta Attention 循环状态的局部注意力；循环记忆通过 PRoPE 注入相机投影几何，并将读出结果用于引导后续历史 KV 查询。模型采用五帧一块的因果扩散生成和按块更新的记忆机制，同时支持完整历史和由水槽帧、全景观测库、近期窗口组成的有界稀疏历史。在 MIND 基准、Unreal Engine 留出轨迹和录制轨迹上，LOCI 在重访保真度方面优于同配方全 Softmax 基线及多种世界模型。在相同有界 KV 预算下，其 PSNR 比全 Softmax 高 0.89 dB；完整历史下高 0.35 dB，并将等长峰值内存降低约 30%。有界模式可在 300 秒视频上以恒定内存运行，但整体绝对生成保真度仍然较低。

## 核心贡献

1. 提出混合空间记忆架构，将带投影相机条件的循环记忆与可直接访问历史观测的 KV 缓存结合，使循环上下文能够影响历史注意力查询，同时保留观测级视觉细节。 2. 将 Kimi Delta Attention 改造用于视频场景记忆：循环读写由 PRoPE 相机几何条件化，采用逐 token 的增量修正，并将通道保留从逐 token 改为逐块执行，使遗忘速率对应经过的视频时间。 3. 提出结合完整历史循环状态与固定容量观测库的有界流式方案。该方案在相同 KV 预算下优于同配方全 Softmax，并可在 300 秒生成过程中保持恒定内存。 4. 在 MIND 记忆基准和留出轨迹上进行了系统评估。完整历史 LOCI 相比全 Softmax 在 Unreal Engine 重访轨迹上提升 0.62 dB PSNR；在有界设置中提升 0.89 dB，并在 MIND 上取得更低 MSE、更高 PSNR 和 SSIM。 5. 通过消融和分析表明，循环状态有助于短期和长期重访一致性，PRoPE 使相机朝向能够从循环状态中被线性解码，且循环读出会促使后续历史注意力更多关注与当前视点共可见的内容。

## 与课题的关系

论文与视频生成、视频扩散和世界模型高度相关：它基于 Wan 5B 视频 Transformer，采用块因果扩散强制训练和逐块去噪采样，用于根据相机轨迹生成可交互视频。其核心问题是动作或相机控制下的闭环空间一致性，即摄像机离开场景后重新返回时恢复原有内容，直接对应行动条件视觉世界模型和闭环模拟。LOCI 结合循环线性记忆、稀疏历史注意力和 KV 缓存，针对长视频生成中的历史访问、空间检索和记忆压缩进行设计。循环状态避免历史信息完全受限于时间近邻，保留观测库则提供细节级检索；因此该方法也涉及实时或流式生成、固定内存、稀疏注意力和缓存复用。实验显示完整历史模式内存降低约 30%，有界稀疏模式可恒定内存生成 300 秒视频，但论文没有重点研究蒸馏或极低延迟实时生成。

## 局限 / 待核实

论文明确指出：留出轨迹主要由 Unreal Engine 渲染，未评估真实世界采集视频；所有模型的绝对保真度仍然较低，基准平均 PSNR 低于 15 dB，因此结果主要应理解为相对改进；实验只使用一个 5B 骨干网络和较短的 5,000 次微调预算；逐 token 保留机制的比较依赖于在短期比较之后定义的扩展指标；30 个模块中的相机注意力分支仍保留显式历史，因此循环路径只减少了主注意力 KV，而不是所有历史存储；训练时循环状态由带噪块特征构建，而推理时则由生成块提交，存在训练—推理差异；有界稀疏模式与全 Softmax 的速度相当依赖于专门优化的循环分支实现。此外，论文未明确说明在更大模型、更多样真实环境、极长时间尺度、不同动作空间或严格实时延迟约束下的表现，也未系统评估模型错误累积、相机轨迹误差以及蒸馏后的性能。
