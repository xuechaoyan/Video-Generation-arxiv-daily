# Code World Model 2.0: Towards Infinite Controllable Video Generation

- **日期**：2026-11-19
- **评分**：75/100
- **作者**：Ruoyu Wang, Hao Zhong, Yanming Yang et al.
- **方向**：Video Generation, World Models
- **论文**：[arXiv 2611.22925](http://arxiv.org/abs/2611.22925v2)
- **代码**：未开源

## Abstract 中文翻译

视觉代理将显式世界状态模拟与逼真视频合成解耦，为离线片段创作和实时交互式流媒体提供了可控接口。然而，实用的渲染器需要解决两个挑战：上游代理会根据交互需求在粗略布局和精细的关节几何之间变化；流式推理必须在少量因果步骤中运行，同时避免自生成历史不断累积误差。我们提出 Invoker-Render，在统一的结构代理、外观参考和语言条件接口下，将双向创作模型与因果四步流式模型结合起来。该模型在一个对齐的约 200 小时多粒度语料库上训练：在提供精细几何约束时遵循这些约束，在粗略代理下合成合理的局部运动，从而支持运行时选择输入细节。为在双向创作和实时流式生成之间衔接，同时避免步数压缩误差与 rollout 漂移叠加，我们提出渐进式强制训练（Progressive Forcing，ProForcing）。ProForcing 首先训练因果预测器，并利用从训练视频构造的历史将其蒸馏为四步渲染器；随后训练转向连续的自生成 rollout。我们还构建了支持高效流式推理的流水线服务栈。实验表明，该方法能够适应不同代理类型、粒度和相机路径，相比近期流式基线取得稳定提升，并在 30 分钟的赛车 rollout 中保持场景与主体外观稳定。

## 全文总结

论文提出 Invoker-Render，一种由视觉代理驱动的视频渲染框架，将双向离线视频创作与四步因果实时流式生成统一在同一条件接口下。模型可处理语义布局、几何结构等不同代理及粗细不同的控制粒度：粗代理约束场景布局、相机和主体根轨迹，细代理进一步约束关节和表面几何。作者提出 ProForcing 训练流程，依次进行因果教师强制与重采样强制、基于数据历史的四步 DMD/GAN 蒸馏，以及基于自生成历史的长序列训练，以降低流式生成中的漂移。配合 KV 缓存、异构编解码和流水线并行，系统在 1344×768 分辨率下达到 18 FPS。140 个测试序列上的盲评显示其在视觉质量、结构运动、参考保持和总体偏好方面均优于比较方法，并展示了约 30 分钟的稳定赛车生成。

## 核心贡献

1. 提出 Invoker-Render，在统一条件接口下结合双向视频创作模型和四步因果流式渲染模型，并支持多种代理表示及多粒度结构控制。2. 提出 Progressive Forcing，将因果适配、少步蒸馏和自生成长序列训练分阶段解耦；其中 RF-DMD 使用数据锚定历史，SF-DMD 再转向连续自生成历史，并结合教师特征相对 GAN 监督。3. 构建约 200 小时的对齐多粒度视频—代理语料库，包含粗细代理、外观参考、结构条件和层次化语言标注。4. 设计面向实时流式渲染的服务栈，包括轻量代理编码器、KV 状态复用、融合执行、跨数据包编解码重叠和异步 CPU 传输，将吞吐提升至 18 FPS。5. 在多种代理、粒度、相机路径和长时赛车场景上验证了结构遵循、外观保持与长时稳定性。

## 与课题的关系

与研究重点高度相关。它直接研究视频扩散模型的因果、流式和长视频生成，并通过四步蒸馏降低实时推理成本。视觉代理承担显式世界状态和动作/几何控制，使该方法适用于动作条件视觉世界模型和闭环模拟中的“状态引擎—神经渲染器”架构。ProForcing 针对自回归历史中的误差累积和长时 rollout 漂移；KV 缓存、少步生成、编码缓存与流水线并行则对应缓存复用、稀疏/高效推理和实时生成需求。论文还明确指出，当前系统尚未实现与交互式状态引擎的闭环耦合，因此在闭环世界模型方向仍有扩展空间。

## 局限 / 待核实

论文明确指出，静态前缀 sink 和滑动 KV 窗口会逐步驱逐活动窗口之外的视觉细节，限制了对远期环境信息的记忆；现有方法缺少显式的长期记忆、空间时间检索或持久化 3D 状态缓存。训练时每个 rollout 窗口使用固定代理粒度，尚不支持流式过程中动态切换细节层级。论文还将与交互式状态引擎进行闭环耦合列为未来工作。实验主要基于约 200 小时数据、140 个测试序列和以赛车为代表的长时 rollout，论文未明确说明在更广泛真实交互环境中的泛化能力。
