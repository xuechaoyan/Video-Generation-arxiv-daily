# Velox: Spatial Memory Makes World Models Efficient

- **日期**：2026-10-19
- **评分**：73/100
- **作者**：Qiuhong Shen, Shizun Wang, Xinchao Wang
- **方向**：Video Generation, World Models
- **论文**：[arXiv 2610.22311](http://arxiv.org/abs/2610.22311v1)
- **代码**：未开源

## Abstract 中文翻译

视频世界模型将动作和相机运动转化为长时视觉 rollout，使视频成为交互式模拟的自然接口。这类交互要求生成具有响应性，但连贯的 rollout 必须保留已生成内容的视觉记忆。分块视频扩散模型通常将这些上下文保存在不断增长的 KV 缓存中，因此后续分块会逐渐变慢。为解决这一瓶颈，我们提出 Velox：一种无需训练的注意力路由器，利用流式几何中的视锥体 slab 对应关系进行区域级上下文选择。Velox 将历史块表示为带有深度区间的相机视锥体 slab，并通过基于新近性的多重变形获取当前块的深度。对于覆盖良好的区域，视锥体 slab 的重叠程度会对模型在各层推导出的块重要性进行软调制；未覆盖区域则保留模型推导的路由，不施加几何偏置。固定的 token 块粒度与 FlashAttention 风格的分块执行相匹配，从而降低随 rollout 长度增长的注意力开销。视锥体 slab 的构建与去噪过程在同一块 H200 上异步运行。在第 48 个分块处，Velox 将注意力加速 4.36 倍，将去噪加速 2.43 倍。在完整的 158 个案例 WBench 导航划分上，其无 API 平均分与稠密 LingBot-Fast-Cam 相差不超过 0.15 分。更多细节请参见项目主页 https://velox-world.com/velox/。

## 全文总结

论文针对长时视频世界模型中 KV 缓存随生成历史增长、导致后续分块越来越慢的问题，提出无需训练的 Velox 推理路由器。它把历史视觉记忆压缩表示为带深度区间的相机视锥体 slab，通过多重变形估计当前块深度，并以世界坐标系中的 slab 重叠作为几何先验，结合每个 Transformer 层自身的注意力重要性，为当前区域选择有限的历史 KV 块。对几何覆盖不足的区域，系统回退到模型路由；同时保留前一分块、全局 Gilbert 邻域和参考帧等局部连续性保护机制。Velox 使用块稀疏注意力、全局对齐的 Gilbert KV 布局，并在 H200 上异步构建几何记忆。在 48 分块 rollout 的末端，注意力和去噪分别获得 4.36 倍和 2.43 倍加速；在 158 个 WBench 导航案例上，质量接近稠密注意力，并略微提升整体平均分。

## 核心贡献

1. 提出 Velox，一种无需训练的区域级注意力路由框架，利用视锥体 slab 对应关系降低分块视频世界模型不断增长的 KV 注意力开销。2. 提出软几何融合规则，以 OBB 视锥体 slab 重叠调制各层模型推导的块重要性，同时对几何覆盖不足的区域保留无偏的模型路由回退。3. 在实现层面结合全局对齐的 Gilbert KV 存储、原生索引块稀疏注意力内核，以及与去噪并行的异步视锥体 slab 构建，在第 48 个分块达到 4.36 倍注意力加速和 2.43 倍去噪加速。4. 通过 WBench 导航评测、缩放实验、几何与模型重要性一致性分析及定性 rollout 对比，验证其在降低延迟的同时维持长时空间一致性的能力。

## 与课题的关系

论文与研究重点高度相关：它直接面向动作和相机控制的视频世界模型及闭环式长时视觉 rollout，解决长视频生成中的历史记忆管理和响应速度问题。方法属于推理阶段的稀疏注意力与 KV 缓存复用，通过空间几何对应关系进行区域级上下文路由，而不是让每个当前区域访问全部历史。固定块路由使注意力开销不再随历史长度线性增长，并在单张 H200 上异步执行几何处理，因而与实时生成、长视频生成、缓存复用和高效视频扩散密切相关。它保持预训练生成器和条件接口不变，也体现了无需再训练即可进行生成加速的路线。

## 局限 / 待核实

论文的实验主要基于 LingBot-Fast-Cam 推理栈、单张 H200 和 158 个 WBench 导航案例，跨模型、硬件和任务的泛化能力未得到充分验证。方法依赖深度、置信度、掩码和相机位姿等流式几何信息；深度空洞、遮挡、错误重建或陈旧的变形深度可能降低路由可靠性。视锥体 slab 状态通常存在两分块的新鲜度延迟，且几何构建与去噪共享同一块 GPU，其他硬件条件下的实际收益可能不同。Velox 使用固定的路由预算和多个校准超参数，可能在不同场景、运动模式或覆盖率下需要重新调整。论文报告了总体质量和部分定性案例，但未明确说明更长于 48 个分块、极端快速相机运动、复杂动态物体或真实交互闭环中的性能。
