# Connected Self Forcing: Beyond Local Learning in Video Autoregression

- **日期**：2026-10-10

- **方向**：Autoregressive and Streaming Video

## Abstract 中文翻译

为了在保持视觉质量和时间一致性的同时流式生成长视频，Self Forcing通过使用带有键值（KV）缓存的自生成历史进行自回滚训练，缓解了暴露偏差。为使内存开销可控，它分离历史缓存，在保留块之间前向依赖的同时切断反向梯度路径。我们提出Connected Self Forcing，一种重新连接自回归块间梯度路径的训练框架，使后续预测的反馈能够指导早期上下文的生成。这些连接超越了历史KV写入：梯度会穿过生成的潜变量，进入产生这些潜变量的计算过程，从而将早期上下文的生成与其在后续预测中的使用联系起来。为使这种连接式训练具备内存效率，我们提出Shortcut Gradient Replay，在无需保留完整回滚计算图的情况下恢复跨块梯度。Connected Self Forcing与分布匹配蒸馏相结合，根据历史块的直接监督及其对后续生成的贡献共同训练历史块。在自回归视频生成实验中，该方法提升了长时域视觉质量和时间一致性，同时不改变推理过程。

## 全文总结

论文指出，Self Forcing虽然通过自生成历史进行训练来缓解训练—推理不一致，但因分离历史KV缓存而切断了后续块向早期块传递的梯度。Connected Self Forcing通过Shortcut Gradient Replay，在不保留完整自回归计算图的前提下恢复从后续预测到历史KV状态及早期生成过程的部分梯度，使每个块不仅为自身生成质量负责，也根据其作为后续上下文的作用进行优化。基于Wan2.1-T2V-1.3B和DMD的实验表明，该方法在约60秒和240秒视频上总体提升了视觉质量、背景一致性、主体一致性和成像质量，并减少了长时域主体与场景漂移；但其动态程度优势取决于初始化方式。

## 核心贡献

1. 识别了Self Forcing中的前向—反向鸿沟：生成块会在前向过程中影响后续预测，但历史分离会阻断后续损失对早期上下文生成的反向监督。 2. 提出Connected Self Forcing，通过Shortcut Gradient Replay恢复跨块梯度路径，并避免保留完整自回归计算图。 3. 通过对历史KV状态进行可微回放，将后续预测的梯度传递至历史块的KV写入和生成计算，同时在目标历史块处终止递归反馈。 4. 将该机制与分布匹配蒸馏结合，在不增加模型参数、不改变推理流程的情况下改善长视频生成。 5. 在60秒和240秒自回归视频评测中验证了视觉质量和时间一致性的改进。

## 与课题的关系

该工作直接面向视频自回归、因果生成、流式生成和长视频生成。它针对按块顺序生成时的暴露偏差与误差累积问题，通过跨块梯度反馈训练历史上下文，从而改善长时域主体、背景和场景一致性。其KV缓存机制和Shortcut Gradient Replay与研究重点中的缓存复用、因果上下文建模和内存高效训练密切相关；与分布匹配蒸馏结合也涉及少步生成和实时生成方向。方法不改变推理过程，因此可直接用于现有因果KV缓存推理管线。不过，论文主要研究视频生成，并未明确涉及动作条件控制、闭环交互式世界模型或真实实时吞吐量评测。

## 局限 / 待核实

Shortcut Gradient Replay以额外重计算换取激活内存降低，训练计算开销因此增加；论文未明确说明其相对于Self Forcing的完整训练时间和吞吐量开销。该方法只恢复选定的跨块梯度路径，并通过在目标历史块处终止反馈来避免递归回放，因此并不等同于完整BPTT。实验主要基于Wan2.1-T2V-1.3B、DMD后训练和特定提示词及评测基准，论文未明确说明其对其他模型架构、训练目标、数据规模或任务类型的泛化能力。实验显示动态程度的表现依赖初始化方式，在部分设置下低于基线；论文未明确说明动作条件控制、闭环交互、真实部署延迟或实时生成性能。
