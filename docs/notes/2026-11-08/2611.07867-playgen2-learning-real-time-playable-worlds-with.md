# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **日期**：2026-11-08
- **评分**：74/100
- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models
- **论文**：[arXiv 2611.07867](http://arxiv.org/abs/2611.07867v1)
- **代码**：未开源

## Abstract 中文翻译

构建一个可玩的世界不仅需要生成逼真的视频，还要求具备响应式控制、持久的空间结构，以及与动态实体进行连贯交互的能力。将生成帧作为唯一的循环世界表示，会使这些要求依赖于视角相关的外观合成，从而难以在生成和交互过程中维持长期的空间与时间一致性。我们提出 PlayGen2，一个将学习到的三维状态演化与神经渲染分离的实时交互式世界模型。PlayGen2维护一个持久化的世界记忆，其中包含由体素占用网格表示的静态几何结构，以及为玩家和其他实体建立的、按身份索引的三维状态。在固定大小的局部区域内，其世界状态模型联合学习动作条件下的实体动力学、几何补全和实体发现，并将更新提交到持久化世界记忆中。一个独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观测，而不会将生成图像反馈到状态预测中。以 Doom 为测试平台，我们证明该模型能够成功学习世界动力学，包括具备几何感知能力的玩家运动以及玩家与非玩家角色之间的交互。在配备 M4 Pro 芯片的 MacBook Pro 上，完整的模拟和渲染流水线后端延迟约为 160 毫秒，体现出较高的计算效率。除单人交互外，我们还展示了在未见过的 Doom 地图上的零样本部署、通过组合单人模型实现多人交互，以及通过基于规则的状态干预实现可编程游戏玩法。这些能力表明，所学习的游戏世界模型具有可迁移性和可扩展性。代码和预训练模型权重均已公开。

## 全文总结

PlayGen2提出了一种将显式三维世界状态演化与神经渲染解耦的可玩世界模型。系统以持久化世界记忆保存体素几何和按身份索引的动态实体状态，在玩家中心的局部三维区域内，根据动作、实体历史和几何信息进行几何补全、实体发现及状态转移；随后由扩散渲染器依据深度、语义投影和有限RGB历史生成第一人称视频，生成帧不再反馈给状态预测。模型仅使用单张Doom地图的结构化游戏数据训练，却在长时域控制、未见地图、离屏NPC行为、多人组合和规则化玩法方面表现出一定泛化能力，并在M4 Pro笔记本上达到约4.98 FPS串行吞吐和约200.6毫秒平均后端延迟。

## 核心贡献

1. 提出基于显式三维状态的可学习世界框架，以体素占用网格表示静态几何，以身份索引状态表示玩家和动态实体，并通过持久化世界记忆支持长期空间一致性。2. 在固定大小的局部区域内联合学习几何补全、实体发现和动作条件下的实体动力学，将状态演化与外观渲染分离。3. 提出由世界状态投影、动作和RGB历史共同条件化的扩散神经渲染器，避免生成图像误差反复进入世界状态预测。4. 在Doom测试平台上展示几何感知的玩家运动、玩家-NPC交互、长时域生成、未见地图零样本迁移、单人模型多人组合，以及基于显式状态干预的可编程玩法。5. 实现面向消费级硬件的交互式运行效率，报告了约160毫秒的后端延迟以及通过并行执行达到7.16 FPS的吞吐。

## 与课题的关系

该工作直接面向动作条件视觉世界模型和闭环模拟：玩家动作驱动显式三维状态转移，状态再决定后续观测，形成持续交互的模拟闭环。它与视频生成和视频扩散的关系在于使用潜空间扩散Transformer将深度、语义地图、动作和视觉历史渲染为第一人称视频，但把视频生成从核心世界状态记忆中剥离。持久化几何、身份化实体状态和离屏实体更新有助于缓解纯自回归视频历史中的空间漂移、实体漂移和长期重访不一致问题。固定大小局部处理、状态与渲染并行及较少扩散步数体现了对实时生成、计算效率和可扩展长时域交互的关注；不过其报告的速度更接近交互式低帧率模拟，而非通常意义上的高帧率实时视频生成。

## 局限 / 待核实

训练数据仅来自ViZDoom中的一张Freedoom2 MAP01地图和规则控制器，训练环境与数据分布较窄；未见地图上的结果主要体现布局迁移，渲染器仍合成训练域的Freedoom2风格，原始纹理差异会影响参考指标。模型在200步内的怪物追踪成功率仅为55%，且实体状态转移不使用运行时碰撞校正，可能导致物理交互误差。串行运行约4.98 FPS、平均后端延迟约200.6毫秒（并行时延迟约275.7毫秒），因此尚未达到常见游戏实时帧率。实验主要使用规则探索控制器和预设评测场景，不能充分证明对更复杂玩家策略或更广泛游戏类型的泛化能力。论文未明确说明在更大规模、多样化数据集上的表现，以及显式状态预测误差长期累积时的稳定性。
