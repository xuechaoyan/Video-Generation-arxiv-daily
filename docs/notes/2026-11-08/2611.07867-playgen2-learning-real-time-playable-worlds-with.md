# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **日期**：2026-11-08
- **评分**：74/100
- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models
- **论文**：[arXiv 2611.07867](http://arxiv.org/abs/2611.07867v1)
- **代码**：未开源

## Abstract 中文翻译

构建一个可玩的世界不仅需要生成逼真的视频，还需要响应迅速的控制、持久的空间结构，以及与动态实体进行连贯交互。仅将生成帧作为循环世界表示，会使这些要求依赖于视角相关的外观合成，从而难以在生成和交互过程中维持长期的空间与时间一致性。我们提出 PlayGen2，一种将学习到的三维状态演化与神经渲染相分离的实时交互式世界模型。PlayGen2 维护一个持久化世界记忆，其中静态几何由体素占用网格表示，玩家和其他实体则由按身份索引的三维状态表示。在固定大小的局部区域内，其世界状态模型联合学习动作条件下的实体动力学、几何补全和实体发现，并将更新提交到持久化世界记忆中。一个独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观测，而不会将生成图像反馈到状态预测中。以 Doom 为测试平台，我们证明该模型能够成功学习世界动力学，包括感知几何的玩家运动以及玩家与 NPC 之间的交互。在配备 M4 Pro 芯片的 MacBook Pro 上，完整的模拟与渲染流程后端延迟约为 160 毫秒，体现出较高的计算效率。除单人交互外，我们还展示了在未见过的 Doom 地图上的零样本部署、通过组合单人模型实现的多人交互，以及通过基于规则的状态干预实现的可编程游戏玩法。这些能力体现了所学习游戏世界模型的可迁移性与可扩展性。代码和预训练模型权重已公开。

## 全文总结

PlayGen2 将可玩世界的模拟与视觉渲染解耦：用持久化的体素几何和按身份索引的实体三维状态表示世界，用动作条件世界状态模型在局部区域内进行几何补全、实体发现和状态转移，再由扩散渲染器生成第一人称视频。模型在仅使用 Freedoom2 MAP01 数据训练的情况下，能够进行具有几何约束的玩家运动、玩家与 NPC 交互、长时域探索和未见地图上的零样本扩展，并支持多人组合及规则化状态干预。在 M4 Pro MacBook Pro 上，串行流程约 4.98 FPS，重叠执行时约 7.16 FPS。

## 核心贡献

1. 提出基于显式三维世界状态的可学习世界框架，将体素占用几何、身份索引实体状态、几何补全、实体发现和动作条件动力学统一到持久化世界记忆中，并与神经渲染解耦。 2. 设计面向实时游玩的世界状态模型，使玩家和 NPC 能够依据动作、历史和局部几何进行状态演化，同时支持未知区域的增量生成。 3. 提出由显式状态投影、RGB 历史和潜空间扩散 Transformer 组成的状态条件渲染器，避免生成图像反馈造成的状态预测误差累积。 4. 在 Doom 上验证了几何感知玩家运动、玩家-NPC 交互、长时域生成、未见地图零样本迁移，以及无需重新训练的多人组合和可编程玩法。 5. 实现了面向消费级硬件的交互式推理效率。

## 与课题的关系

PlayGen2 与研究重点高度相关。它是动作条件的视觉世界模型，但不依赖生成视频帧作为唯一循环状态，而是通过持久化显式三维状态实现闭环模拟，因此能够维持空间结构、追踪视野外实体并支持重新访问。其世界状态模型在固定大小的玩家中心局部区域中进行因果式状态更新和增量世界生成，适合长时域、流式交互。独立的扩散渲染器将状态投影转换为视频，并结合 RGB 历史维持视觉连续性；论文还报告了约 160 毫秒后端延迟、4.98 FPS 的串行吞吐率和重叠执行下 7.16 FPS，直接涉及实时生成与高效推理。模型通过共享状态接口支持多人组合和规则干预，体现了闭环仿真、状态编辑和可组合性的价值。

## 局限 / 待核实

论文的训练数据仅来自 Freedoom2 MAP01，约 500 小时且由规则控制器采集，因此训练分布和游戏类型较为有限；实验主要集中在 Doom 风格环境，尚未证明对更复杂或更真实世界的迁移能力。模型的实体状态只在活动局部区域内持续模拟，局部区域之外的实体不会被连续更新。论文明确说明运行时不进行碰撞校正，且玩家-NPC 追踪实验的成功率为 55%。渲染器主要学习 Freedoom2 的视觉风格，在未见地图上无法恢复原生纹理，相关参考指标会受到外观差异影响。串行执行的平均后端延迟为 200.6 毫秒，完整交互仍未达到通常意义上的高帧率实时视频。论文未明确说明在更大规模、多样化实体类型或更长时间跨度下的性能上限。
