# Connected Self Forcing: Beyond Local Learning in Video Autoregression

- **方向**：Autoregressive and Streaming Video

## Abstract 中文翻译

为了在保持视觉质量和时间一致性的同时流式生成长视频，Self Forcing通过利用带有键值（KV）缓存的自生成历史进行自回归 rollout 训练，缓解了暴露偏差。为控制内存开销，它将历史缓存从计算图中分离，在保留块之间前向依赖的同时切断反向梯度路径。我们提出 Connected Self Forcing，一种重新连接自回归块之间梯度路径的训练框架，使后续预测的反馈能够指导更早上下文的生成。这些连接超越了历史 KV 写入：梯度会穿过生成的潜变量，进入产生这些潜变量的计算过程，从而将早期上下文的生成与其在后续预测中的使用联系起来。为使这种连接式训练具备内存效率，我们提出 shortcut gradient replay，在无需保留完整 rollout 计算图的情况下恢复跨块梯度。结合分布匹配蒸馏，Connected Self Forcing根据历史块自身的直接监督及其对后续生成的贡献共同训练这些块。在自回归视频生成实验中，该方法提升了长时域视觉质量和时间一致性，同时不改变推理过程。

## 全文总结

论文指出，Self Forcing虽然通过自生成历史训练来匹配推理分布，但因历史KV缓存被detach，后续块对早期块的反向监督会丢失。Connected Self Forcing通过Shortcut Gradient Replay重建从后续预测到历史KV状态及早期生成过程的跨块梯度，在不保留完整自回归计算图的前提下，以较低激活内存换取重计算。该方法结合DMD训练，不增加参数且不改变推理流程。在Wan2.1-T2V-1.3B上的60秒和240秒实验中，相比Self Forcing及相关基线，整体质量、背景和主体一致性等指标普遍提升，并减少了长视频中的主体与场景漂移。

## 核心贡献

1. 识别了Self Forcing中的前向—反向鸿沟：生成块会在前向过程中影响未来预测，但历史detach阻断了未来损失回传至早期上下文生成的路径。 2. 提出Connected Self Forcing，通过Shortcut Gradient Replay利用后续块直接读取历史KV缓存这一依赖，恢复跨块梯度，并将反馈传回历史KV写入和生成过程。 3. 在不保留完整rollout计算图、不增加模型参数且不改变推理过程的情况下实现内存高效训练。 4. 通过60秒和240秒长时域自回归视频实验及消融实验，验证了视觉质量和时间一致性方面的改进。

## 与课题的关系

该工作直接针对视频自回归、因果、流式和长视频生成中的训练问题。它使用自生成历史、KV缓存和分块自回归rollout来匹配在线推理，并通过跨块梯度连接提升长时域主体与场景一致性，因此与长视频生成、缓存复用和因果视频模型高度相关。其结合分布匹配蒸馏和四步采样，也与视频生成加速和蒸馏有关。方法只改变训练阶段，推理时仍使用原有的因果KV缓存流程；论文未涉及动作条件、闭环交互模拟或实时系统吞吐量的直接评估。

## 局限 / 待核实

论文的实验主要基于Wan2.1-T2V-1.3B、文本到视频DMD后训练和特定提示集，外推到其他架构、数据规模及条件形式的效果尚未得到充分验证。Shortcut Gradient Replay以重计算换取激活内存降低，论文未在正文中完整量化其训练时间和计算开销。CSF的质量与动态程度存在初始化和反馈权重相关的权衡，部分设置下动态程度低于基线。实验重点是离线长时域视频质量和一致性，未明确说明真实交互闭环、动作条件控制、实时延迟或部署吞吐量表现。作为预印本，论文未明确说明更大规模训练和更长时间范围下的稳定性。
