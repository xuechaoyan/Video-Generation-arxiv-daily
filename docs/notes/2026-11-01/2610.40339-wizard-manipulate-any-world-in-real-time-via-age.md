# Wizard: Manipulate Any World in Real Time via Agentic Control

- **方向**：Video Generation, World Models

## Abstract 中文翻译

近年来，视频世界模型的发展使得生成越来越逼真且具有交互性的虚拟环境成为可能，为玩家可定制的游戏玩法开辟了新的可能性。智能体框架进一步推动了这一方向的发展，将显式游戏逻辑和可控的世界表示与视觉生成解耦。然而，现有方法仅支持简单的游戏设置和预定义的运动模式，对未见过的环境和角色泛化能力较差，并且实时交互能力有限。本文提出 Wizard，一种智能体游戏世界模型，能够实时、精确地控制角色运动，并对新场景、新角色和新动作实现零样本泛化。为此，我们构建了一个涵盖 750 个场景和 178 个角色的多样化数据集，并将骨骼与几何信息作为结构化表示。我们利用这些表示作为中间代理来条件控制视频生成模型，同时引入自适应掩码机制，以改善条件信号与生成视频轨迹之间的对齐。此外，我们提出一个智能体框架，显式维护并更新游戏状态，使玩家能够自由配置虚拟世界、细粒度地控制角色运动，同时保持视觉质量和游戏玩法的一致性。通过将智能体控制与基于结构化代理的生成相结合，我们的框架为玩家驱动的游戏创作带来了新的可能性，实现了实时、可泛化且机制一致的世界模拟。

## 全文总结

Wizard 是一个面向可定制游戏的智能体视频世界模型。系统从用户提供的场景图像和角色图像出发，利用场景几何代理与角色关节骨骼控制视频生成，并由智能体显式维护角色状态、战斗规则、场景几何和动作规划。作者构建了包含 50.3 小时数据、750 个场景和 178 个角色的数据集，通过动作检索与重定向支持新角色，通过自适应角色注意力掩码保持外观与位置对应。模型基于 Wan2.2-TI2V-5B，经因果适配和少步蒸馏后，结合有限 KV 缓存以 24 FPS、2 步去噪进行流式生成。实验主要通过定性示例展示其对未见场景、角色和动作的零样本泛化，以及角色变换、场景操纵和机制一致的战斗玩法。

## 核心贡献

1. 提出 Wizard 智能体游戏世界模型，通过结构化场景几何和角色骨骼实现细粒度控制、零样本泛化、实时交互与机制一致的游戏玩法。\n2. 构建覆盖 750 个场景和 178 个角色的多源数据集，共 50.3 小时，统一对齐场景几何、角色骨骼与视频。\n3. 提出基于代理的视频到视频智能体框架，将场景构建、角色动画、游戏逻辑和视觉生成解耦，并支持状态感知的战斗控制。\n4. 利用骨骼提供的角色位置构建自适应注意力掩码，将角色参考图像绑定到对应区域，改善角色身份保持及参考图像与生成视频之间的对齐。\n5. 结合因果适配、少步蒸馏和有限 KV 缓存，实现 24 FPS、2 步去噪的实时自回归视频生成。

## 与课题的关系

该工作与视频生成和视频扩散直接相关：它基于 Wan2.2-TI2V-5B，通过几何与骨骼代理条件控制视频生成，并使用自适应注意力掩码保持角色外观一致。它属于动作条件视觉世界模型，将玩家输入转化为角色动作、相机运动和场景编辑，并通过显式世界状态、行为规划和规则控制形成闭环游戏模拟。它还明确涉及自回归、因果生成、长时流式生成、实时生成、少步蒸馏、稀疏的区域注意力约束以及 KV cache 复用。模型保留 20 个近期潜变量帧和 1 个持久汇聚帧，在有限内存下持续生成，并以 24 FPS 运行。

## 局限 / 待核实

论文明确指出两项局限：第一，系统依赖动作库，因此难以为具有罕见身体结构的角色找到兼容动作；第二，在更长的视频轨迹中，场景代理与生成视频之间的一致性可能下降。论文还将支持更灵活、更真实的角色动作，以及维持长时场景外观一致性列为未来工作。
