# Astronex-World 1.0: Real-Time Interactive World Model Foundation

- **日期**：2026-09-21
- **评分**：74/100
- **作者**：Xin Zhou, Cong Miao
- **方向**：World Models
- **论文**：[arXiv 2609.20034](http://arxiv.org/abs/2609.20034v1)
- **代码**：未开源

## Abstract 中文翻译

我们提出 Astronex-World 1.0，一个开放且可控的视频世界模型基础。给定文本提示（文本生成视频）或初始观测（图像生成视频），该模型能够在帧对齐的相机轨迹、连续动作和具身标识符条件下预测未来视觉状态，并接受插入到推演指定位置的文本事件。该模型系列提供用于全上下文生成的双向模型，以及采用块因果注意力和跨块 KV 缓存、用于持续生成的因果模型；两者均基于 Wan2.2-TI2V-5B 先验构建。PRoPE 注入相机内参与外参，64 维动作流调制每个 Transformer 层。五阶段训练流程依次实现双向相机与动作控制、将主干转换为块因果生成、蒸馏少步学生模型、恢复混合域动态，并应用非对称 DMD/DMD2 分布匹配。因果模型以 24 fps 生成 832×480 视频。全部五个训练阶段均可在两块 NVIDIA L20 48 GB GPU 上运行，因果模型则可在单块 GPU 上实时流式生成。在 WBench Navi 和 WBench Full 上，该模型分别取得 73.5 和 70.0 分。在 Full 测试中，这个 5B 模型得分高于 13.6B 的 LongCat-Video 和 14B 的 Helios，与 22B 的 LTX-2.3 相差不到 1 分，并高于使用相同 5B 先验、在 NVIDIA A100 GPU 上进行后训练的 YUME 1.5。预留的动作输入和输出接口支持后续针对具身智能与自动驾驶的后训练。

## 全文总结

Astronex-World 1.0 是一个基于 Wan2.2-TI2V-5B 的 5B 可控视频世界模型基础，提供双向和因果两种形态，统一支持文本、图像、相机、连续动作、具身标识符及事件控制。模型通过 PRoPE 注入相机几何信息，并在每个 Transformer 层调制动作条件；因果版本采用块因果注意力、局部历史窗口、持久注意力汇聚帧、KV 缓存和少步 UniPC，实现长时持续生成与单块 L20 上的实时流式推理。五阶段训练包括双向控制适配、块因果转换、在线轨迹蒸馏、混合域因果 SFT 以及非对称 DMD/DMD2。模型在 WBench 上取得较强成绩，但复杂交互、长时漂移、运动幅度和物理真实性仍存在明显不足。

## 核心贡献

1. 提出共享 5B 视频主干的双向与因果模型系列，分别面向高质量离线生成及可缓存、持久的交互式生成，并支持文本生成视频和图像生成视频。2. 提出统一控制接口：通过 PRoPE 注入完整相机内参与外参，使用 64 维连续动作和具身标识符调制全部视觉层，并提供定时文本事件接口及可后训练的动作序列输出接口。3. 提出五阶段训练流程，包括双向控制适配、块因果教师强制、在线 UniPC 轨迹蒸馏、混合域因果监督微调和非对称 DMD/DMD2 分布匹配。4. 结合块因果注意力、跨块 KV 缓存、局部历史窗口和持久汇聚帧，实现 832×480、24 fps 的实时流式生成。5. 在 WBench 158 和 289 任务以及部分 VBench 评测中验证模型，并展示了仅使用两块 L20 GPU 进行后训练、单块 L20 GPU 实时推理的效率。

## 与课题的关系

论文与视频生成和视频扩散高度相关：它直接复用 Wan2.2-TI2V-5B 的视频 DiT 与流匹配生成框架，并通过 UniPC 采样和 DMD/DMD2 蒸馏实现少步视频生成。它面向动作条件视觉世界模型和闭环模拟，使用逐帧相机轨迹、连续动作、具身标识符及定时事件预测未来视觉状态，且支持将生成历史反馈为后续上下文。它与自回归、因果、流式和长视频生成直接相关：因果模型采用块下三角注意力，只访问历史信息，以 KV 缓存复用已完成块，并通过局部窗口和持久汇聚帧维持长时上下文。它也与实时生成、蒸馏、稀疏注意力和缓存复用直接相关：少步 UniPC、在线轨迹蒸馏、DMD/DMD2、块级注意力和跨块 KV 缓存共同支持单块 L20 上的实时 24 fps 流式输出。

## 局限 / 待核实

论文明确指出，复杂交互能力较弱：事件编辑、主体动作和视角切换主要依赖有限的文本切换接口，无法表达多个相互独立的定时事件。长时生成仍存在颜色漂移、场景变暗、结构重绘、细节丢失以及回转后场景不可逆等问题。DMD 蒸馏会抑制主体运动，导致生成结果偏静态，内部运动幅度显著低于双向教师模型。模型没有显式物理状态、深度、碰撞约束或 3D 场景表示，因此视频连贯性不能证明物理准确性。64 维动作输入和动作序列输出接口仍需通过领域数据进行自动驾驶或机器人后训练。VBench 结果仅覆盖部分数据集（240 个 T2V 和 118 个 I2V 视频），不能视为完整评测；论文未明确说明更大规模或更全面真实闭环任务中的泛化能力。
