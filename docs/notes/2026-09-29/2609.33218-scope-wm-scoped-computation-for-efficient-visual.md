# Scope-WM: Scoped Computation for Efficient Visual World Models

- **日期**：2026-09-29
- **评分**：80/100
- **作者**：Chunzheng Li, Zesheng Jia, Hongda Zhang et al.
- **方向**：World Models
- **论文**：[arXiv 2609.33218](http://arxiv.org/abs/2609.33218v1)
- **代码**：未开源

## Abstract 中文翻译

视觉世界模型通过预测未来观测来支持机器人规划，但稠密潜状态传播和高样本量轨迹优化会带来较高的推理延迟与峰值内存使用，限制其在资源受限平台上的实时部署。现有稀疏世界模型加速方法要么依赖无引导的标记稀疏化，可能丢弃与规划相关的信息并限制可实现的稀疏程度；要么引入复杂的辅助模块和繁琐的多阶段训练流程。本文提出 Scope-WM，一种高效的视觉世界模型，将计算范围限定在与预测相关的潜在区域和有前景的动作序列上。Scope-WM 将预测相关性蒸馏到一个轻量级的动作条件选择器中，仅对选定的少量标记执行完整动力学预测。对于其余标记，模型利用前景状态及其变化的紧凑摘要进行更新，使背景能够感知前景动力学，同时避免昂贵的标记间交互。在规划过程中，Scope-WM 保留并复用初始模型预测控制（MPC）搜索中发现的高质量动作序列，在减少后续 rollout 预算的情况下集中进行搜索。该流程只需进行一次选择器蒸馏，随后对稀疏世界模型进行单阶段联合训练。在具有挑战性的 Push-T 任务上，相比稠密 DINO-WM，Scope-WM 将峰值 GPU 内存使用量和规划时间分别降至其 18.1% 和 14.3%，对应 6.97 倍的规划加速，同时保持具有竞争力的任务性能。在五个不同的视觉规划任务上的进一步评估展示了 Scope-WM 的普适性。代码已公开于 https://github.com/ChunZheng2022/Scope-WM。

## 全文总结

本文针对基于视觉世界模型的机器人规划中潜状态传播和采样式 MPC 计算成本高的问题，提出 Scope-WM。该方法在三个层面分配计算：使用蒸馏相关性选择（DRS）根据视觉状态、控制状态和动作选择需要完整动力学预测的少量标记；使用前景-变化量背景更新（FDBU）通过前景状态及其运动变化的汇总信息轻量更新背景标记；使用精英库交叉熵方法（EB-CEM）在初始 MPC 步骤投入更多采样，并在后续步骤复用高质量动作序列。实验基于 DINO-WM，在 PointMaze、Wall、Push-T、Rope 和 Granular 五项任务上进行。Push-T 上最激进的 32 标记配置将规划时间和峰值 GPU 内存分别降至稠密基线的 14.3% 和 18.1%，实现 6.97 倍加速，同时成功率为 88%；较宽松的 98 标记配置成功率达到 94%。消融实验表明，DRS、FDBU 和 EB-CEM 分别有助于相关标记选择、背景状态维护和低预算轨迹搜索。

## 核心贡献

1. 将高效视觉世界模型规划表述为三层计算分配问题，涵盖预测相关标记选择、前景感知的背景更新和轨迹搜索预算分配。 2. 提出 DRS，通过从完整标记教师模型中蒸馏预测相关性，利用轻量级动作条件选择器确定需要完整动力学预测的标记，并仅需一次选择器蒸馏。 3. 提出 FDBU，利用前景状态和前景变化量的汇总上下文，以轻量级门控残差更新背景标记，避免稠密的前景-背景标记交互。 4. 提出 EB-CEM，在初始 MPC 搜索中使用更大的采样预算，并将高质量动作序列存入精英库，在后续低预算搜索中复用和扰动这些序列。 5. 在五个视觉规划任务上验证了方法的效率-性能权衡，并在 Push-T 上实现显著的规划时间和显存降低。

## 与课题的关系

该论文与研究重点直接相关，核心对象是用于机器人闭环规划的视觉世界模型。它通过动作条件的预测相关性选择实现状态和动作依赖的稀疏计算，通过前景动力学摘要实现低成本潜状态更新，并通过精英动作序列复用减少后续 MPC 搜索开销。这些设计对应稀疏注意力或稀疏 token 计算、缓存/轨迹复用、实时推理和闭环视觉模拟。方法不是视频生成或视频扩散模型，也不是自回归像素级长视频生成；其预测对象是 DINOv2 特征空间中的未来视觉潜状态，主要目标是提高动作条件视觉世界模型的规划效率。

## 局限 / 待核实

论文在 Rope 任务上的稀疏模型性能明显低于稠密 DINO-WM：最佳 Scope-WM 的 Chamfer Distance 为 0.71，而 DINO-WM 为 0.41，说明在更复杂的可变形动力学场景中，稀疏前景预测和汇总式背景更新可能损失重要信息。更激进的稀疏配置也会带来一定性能下降，例如 Push-T 的 32 标记配置成功率为 88%，低于稠密模型的 90%，而 98 标记配置为 94%。DRS 依赖预先训练的稠密 DINO-WM 教师和一次蒸馏，FDBU 使用前景状态与变化量的汇总表示，可能无法完整表达复杂的标记间关系。实验主要基于五项离线视觉规划任务和有限的 GPU 平台，论文未明确说明在真实机器人、更多样的长时域任务、不同视觉编码器或大规模实时部署中的表现。该方法的训练和推理开销、超参数敏感性及其与视频扩散或生成式世界模型的比较，论文未明确说明。
