# Connected Self Forcing: Beyond Local Learning in Video Autoregression

- **方向**：Autoregressive and Streaming Video

## Abstract 中文翻译

为在保持视觉质量和时间一致性的同时流式生成长视频，Self Forcing 通过使用带有键值（KV）缓存的模型自生成历史进行自回归训练，缓解了暴露偏差。为控制内存开销，它会分离历史缓存，在保留块之间前向依赖的同时切断反向梯度路径。我们提出 Connected Self Forcing，这是一种重新连接自回归块之间梯度路径的训练框架，使后续预测产生的反馈能够指导早期上下文的生成。这些连接超越了历史 KV 写入：梯度会穿过生成的潜变量，进入产生这些潜变量的计算过程，从而将早期上下文的生成与其在后续预测中的使用联系起来。为使这种连接式训练具备内存效率，我们提出 shortcut gradient replay，在无需保留完整 rollout 计算图的情况下恢复跨块梯度。结合分布匹配蒸馏后，Connected Self Forcing 会根据历史块的直接监督及其对后续生成的贡献共同训练这些块。在自回归视频生成实验中，该方法提升了长时域视觉质量和时间一致性，同时不改变推理过程。

## 全文总结

论文指出，Self Forcing 虽然通过模型自身生成的历史进行训练来缓解训练—推理不一致，但由于分离历史 KV 缓存，后续块的损失无法反向影响早期块的生成，形成跨块梯度缺口。Connected Self Forcing（CSF）通过 Shortcut Gradient Replay，使后续预测的梯度经历史 KV 状态回传至早期块的上下文写入和生成过程，同时避免保存完整自回归计算图。该方法不增加参数且不改变推理流程，在 Wan2.1-T2V-1.3B 上结合 DMD 训练，在约 60 秒和 240 秒视频评测中相较 Self Forcing 和 Self Gradient Forcing 改善了多项视觉质量、主体一致性和背景一致性指标，并减少了长时间生成中的主体与场景漂移。

## 核心贡献

1. 识别了 Self Forcing 中的前向—反向不一致：生成块会在前向过程中影响后续预测，但历史缓存分离会阻断后续损失返回早期上下文生成的梯度。 2. 提出 Connected Self Forcing 及 Shortcut Gradient Replay，通过对历史 KV 状态进行可微重放，恢复选定的跨块梯度路径，而无需保留完整自回归计算图。 3. 将历史块同时按自身生成质量及其作为后续上下文的作用进行训练，并保持参数规模和推理过程不变。 4. 在 60 秒和 240 秒自回归视频生成实验中展示了更好的长时域视觉质量和时间一致性。

## 与课题的关系

该工作直接针对视频自回归、因果和流式长视频生成：它使用模型自生成历史、KV 缓存和块级自回归 rollout，使训练条件与流式推理一致。Shortcut Gradient Replay 属于缓存/重放式训练机制，通过牺牲部分重计算降低长时域训练的激活内存需求；结合分布匹配蒸馏，也与少步生成和生成加速相关。其核心目标是抑制长视频中的主体、背景和场景漂移，因此与长视频生成、时间一致性和实时或低延迟因果生成密切相关。论文未涉及动作条件控制、闭环交互式世界模型或显式的实时吞吐评测。

## 局限 / 待核实

实验主要基于 Wan2.1-T2V-1.3B、DMD 后训练和文本到视频设置，论文未证明方法对其他架构、模型规模或条件形式的普适性。训练阶段通过梯度重放换取较低激活内存，但会引入额外重计算；不同方法的完整训练时间、吞吐和显存—速度权衡在正文中未充分量化。评测主要覆盖约 60 秒和 240 秒视频、有限的提示词集合及若干 VBench 指标，不能完全代表真实交互式或实时部署场景。方法需要选择可直接访问的历史 KV 状态，适用范围及对更复杂历史记忆机制的效果论文未明确说明。论文还未报告动作条件控制、闭环环境交互或实际实时生成延迟。
