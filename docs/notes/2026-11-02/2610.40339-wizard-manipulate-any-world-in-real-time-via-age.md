# Wizard: Manipulate Any World in Real Time via Agentic Control

- **日期**：2026-11-02
- **评分**：77/100
- **作者**：Yuzhe Wu, Zijun Lin, Yeying Jin
- **方向**：Video Generation, World Models
- **论文**：[arXiv 2610.40339](http://arxiv.org/abs/2610.40339v1)
- **代码**：未开源

## Abstract 中文翻译

近年来，视频世界模型的发展使生成越来越逼真且具有交互性的虚拟环境成为可能，为玩家可定制的游戏玩法开辟了新的方向。智能体框架进一步推动了这一方向的发展，将显式游戏逻辑和可控的世界表示与视觉生成解耦。然而，现有方法仅支持简单的游戏场景和预定义的运动模式，对未见过的环境和角色泛化能力较差，且实时交互能力有限。本文提出 Wizard，一种智能体游戏世界模型，能够实时、精确地控制角色运动，并以零样本方式泛化到全新的场景、角色和动作。为此，我们构建了一个涵盖 750 个场景和 178 个角色的多样化数据集，并将骨骼与几何信息纳入结构化表示。我们利用这些表示作为中间代理来条件化视频生成模型，并结合自适应掩码机制，改善条件信号与生成视频 rollout 之间的对齐。此外，我们引入一种智能体框架，显式维护和更新游戏状态，使玩家能够自由配置虚拟世界并对角色运动进行细粒度控制，同时保持视觉质量和游戏玩法一致性。通过结合智能体控制与基于结构化代理的生成，我们的框架为玩家驱动的游戏创作带来了新的可能，实现了实时、可泛化且具有机制一致性的世界模拟。

## 全文总结

Wizard 是一个面向可定制游戏世界的智能体视频世界模型。系统从用户提供的场景图像和角色图像出发，利用几何重建、角色网格与骨骼绑定，将场景表示为可编辑的几何代理，将角色表示为可控的关节骨骼；再通过动作检索和重定向为新角色构建动作集合。智能体显式维护角色位置、姿态、生命值、攻击阶段、技能冷却等状态，并通过规则控制器和行为规划器实现具有战斗机制一致性的闭环交互。视频生成器基于 Wan2.2-TI2V-5B，以场景几何、角色骨骼、参考图像和历史帧为条件，通过角色感知的自适应注意力掩码保持角色外观与位置对齐。作者构建了包含 50.3 小时数据、750 个场景和 178 个角色的数据集，并采用因果适配、少步蒸馏和 KV 缓存实现实时自回归生成。论文展示了对未见场景、角色和动作的零样本泛化，以及角色变换、场景操纵和状态感知战斗等开放式玩法；系统报告可在 24 FPS 下、仅用 2 步去噪生成视频。

## 核心贡献

1. 提出 Wizard 智能体游戏世界模型，通过结构化场景几何和角色骨骼实现细粒度角色与场景控制、零样本泛化、实时交互和机制一致的游戏玩法。 2. 构建包含 50.3 小时数据、750 个场景和 178 个角色的多源数据集，统一提供对齐的场景几何、角色骨骼和视频数据。 3. 提出基于代理的视频到视频智能体框架，将场景构建、角色动画、游戏逻辑和视觉生成解耦，并支持状态感知的战斗控制。 4. 提出利用骨骼位置构造的角色感知自适应注意力掩码，将角色参考图像绑定到对应空间区域，改善角色身份保持和参考图像与生成视频之间的对齐。 5. 结合因果适配、少步蒸馏以及保留近期潜变量和持久注意力汇聚帧的 KV 缓存，实现面向实时交互的流式自回归视频生成。

## 与课题的关系

该工作与研究重点高度相关：它是一个动作条件和状态条件的视频世界模型，将玩家输入转换为角色骨骼、场景几何和游戏状态，再由因果视频生成器闭环渲染未来观测。其显式状态维护、规则执行和行为规划支持闭环模拟，而不是单纯根据像素历史生成视频。方法直接涉及因果、自回归、流式和长时生成，通过 20 个近期潜变量帧加一个持久汇聚帧的 KV 缓存实现有界内存推理，并通过因果适配与少步蒸馏达到 24 FPS、2 步去噪的实时生成。结构化代理、稀疏的角色感知注意力掩码和缓存复用共同提升了空间控制、角色身份保持与多角色交互能力。论文还展示了对新场景、新角色和新动作的零样本泛化，以及角色召唤或变换、场景编辑和机制一致战斗等可交互世界模拟能力。

## 局限 / 待核实

论文明确指出两项局限：第一，系统依赖动作库，对于具有罕见身体结构的角色，可能难以找到兼容动作；第二，在更长的视频 rollout 中，场景代理与生成视频之间的一致性可能下降。论文还指出未来需要支持更灵活、更真实、更加贴合实际游戏的角色动作，并维持长时间 rollout 中的场景外观一致性。除此之外，论文未明确说明更长时长下的定量一致性指标、与现有方法的系统性定量比较、生成延迟和硬件配置对 24 FPS 结果的影响，以及复杂开放世界中的物理真实性和可扩展性。
