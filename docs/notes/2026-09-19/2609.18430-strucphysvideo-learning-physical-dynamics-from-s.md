# StrucPhysVideo: Learning Physical Dynamics from Structured Captions and Robot Actions

## Abstract 中文翻译

物理动力学建模——包括物体如何运动、相互作用以及改变状态——是面向具身智能的视频世界模型的核心。我们提出 StrucPhysVideo，一系列将面向物理的数据筛选与语言、动作条件下的场景演化预测相结合的视频世界模型。我们的数据处理流程结合了运动感知的视频分割、质量与内容过滤、物理相关性验证，以及对物体、材料和时间局部化交互的结构化标注。通过解耦相机运动与物体行为，并明确描述接触、形变和状态转移，该流程提供了以可观测物理事件为基础的监督信号。在此数据基础上，我们提出 StrucPhysVideo-TI2V，这是一种稀疏混合专家（MoE）文本-图像到视频模型，通过逐步强化物理动力学、同时保留通用领域视频数据的课程学习进行训练。StrucPhysVideo-TI2V 在 Physics-IQ Verified 上取得了 45.5% 的成绩，达到当前最佳水平，并以 2.8 个百分点超过 Cosmos3-Super-Image2Video。针对不同骨干网络的字幕消融实验进一步证明了面向物理的监督信号的有效性。我们还将 StrucPhysVideo-TI2V 扩展为 StrucPhysVideo-IA2V，一种交互式图像-动作到视频世界模型，可根据机器人末端执行器指令预测视觉结果。动作条件、因果自回归生成和少步蒸馏使模型能够仅用四个去噪步骤进行增量式机器人 rollout。总体而言，StrucPhysVideo 推动物理动力学建模从图像和语言条件下的视频预测，迈向动作驱动的交互。

## 全文总结

本文提出 StrucPhysVideo，旨在学习物体运动、接触、形变和状态变化等物理动力学。作者构建了包含镜头切分、运动感知片段选择、技术质量过滤、内容纯度过滤、物理相关性验证和结构化标注的数据流程，将场景、材料、物体行为、时间顺序及相机运动分别记录。基于这些数据，StrucPhysVideo-TI2V 使用稀疏 MoE 视频 Transformer 和课程学习进行文本-图像到视频生成，在 Physics-IQ Verified 上获得 45.5% 的成绩。进一步地，StrucPhysVideo-IA2V 将机器人末端执行器轨迹作为条件，通过动作编码、因果化训练和三阶段少步蒸馏实现流式自回归视频预测，在 AgiBot 数据上的视觉保真度、轨迹一致性和交互质量均优于所比较的 DreamDojo-AgiBot。

## 核心贡献

1. 提出面向物理交互的视频数据筛选流程，结合镜头边界检测、运动感知窗口选择、技术质量检查、内容纯度过滤和多模态物理验证，保留具有连续且可观察物理过程的片段。 2. 提出结构化物理字幕与标签体系，分别描述全局场景动力学、相机运动与光照、世界知识与材料属性，以及带时间戳的实体级行为、接触、形变和状态变化。 3. 提出 StrucPhysVideo-TI2V，一种结合冻结视觉语言编码器、视频 VAE、稀疏 MoE 时空 Transformer 和首帧约束流匹配的文本-图像到视频模型，并通过物理数据课程学习提升动力学预测能力。 4. 提出 StrucPhysVideo-IA2V，将机器人末端执行器动作注入视频扩散模型，并通过教师强制自回归扩散训练、因果 ODE 初始化和非对称分布匹配蒸馏，得到四步去噪的因果流式生成器。 5. 通过 Physics-IQ Verified、字幕消融和机器人视频实验，验证物理字幕监督及动作条件对物理合理性、动作一致性和视频质量的提升。

## 与课题的关系

本文与研究重点高度相关。它直接研究视频世界模型和视频扩散生成，并将物理动力学作为训练目标。StrucPhysVideo-IA2V 使用机器人动作作为条件，预测动作导致的视觉后果，属于动作条件视觉世界模型和闭环仿真的基础技术。其因果自回归建模支持按时间块进行流式、增量式 rollout；四步去噪蒸馏则面向实时生成和低延迟交互。模型还采用稀疏 MoE 以控制每个 token 的专家计算量，并通过教师蒸馏将多步扩散采样压缩为少步生成。不过，论文主要展示离线视频预测和 rollout 评估，尚未证明与实际策略或机器人控制器组成完整闭环。

## 局限 / 待核实

论文明确指出，当前模型仍需扩展到更长时间范围的流式 rollout，并在长期生成中保持物理一致性；推理延迟仍需进一步降低，目标是达到一到两步生成。模型还需要支持更丰富的动作空间，并实现不同机器人平台之间的跨 embodiment 泛化。论文的机器人实验主要使用 AgiBot 数据和末端执行器目标位姿表示，动作表示及平台覆盖范围有限。论文还指出，现有物理标注不包含绝对质量、力大小、真实速度和温度，因为仅凭视频通常无法可靠估计这些量。除此之外，论文未明确说明真实机器人闭环控制、长期误差累积和大规模独立数据集上的泛化性能。
