# StrucPhysVideo: Learning Physical Dynamics from Structured Captions and Robot Actions

## Abstract 中文翻译

物理动力学建模——包括物体如何运动、相互作用以及改变状态——是面向具身智能的视频世界模型的核心。我们提出 StrucPhysVideo，一个视频世界模型系列，通过物理学导向的数据整理，以及语言和动作条件下的场景演化预测，将二者连接起来。我们的数据流程结合了运动感知的视频分割、质量与内容过滤、物理相关性验证，以及对物体、材料和时间局部化交互的结构化标注。通过将相机运动与物体行为解耦，并明确描述接触、形变和状态转移，该流程提供了以可观测物理事件为基础的监督信号。在此类数据基础上，我们提出 StrucPhysVideo-TI2V，这是一种稀疏混合专家（MoE）文本-图像到视频模型，采用课程式训练，逐步强调物理动力学，同时保留通用领域视频数据。StrucPhysVideo-TI2V 在 Physics-IQ Verified 上取得 45.5% 的得分，达到当前最优性能，并以 2.8 个百分点超过 Cosmos3-Super-Image2Video。针对不同骨干网络的 caption 消融实验进一步证明了物理导向监督的有效性。我们还将 StrucPhysVideo-TI2V 扩展为 StrucPhysVideo-IA2V，一种交互式图像-动作到视频世界模型，用于根据机器人末端执行器指令预测视觉结果。动作条件、因果自回归生成和少步蒸馏使其能够仅用四个去噪步骤进行增量式机器人 rollout。总体而言，StrucPhysVideo 将物理动力学建模从图像和语言条件的视频预测推进到了动作驱动的交互。

## 全文总结

本文提出 StrucPhysVideo，旨在学习物体运动、接触、形变和状态变化等物理动力学。工作首先构建物理导向的数据流程，通过镜头与运动感知分割、技术质量过滤、内容纯度过滤、物理相关性验证，以及包含物体、材料、相机运动和时间定位交互的结构化描述，筛选并标注视频数据。基于这些数据，作者训练了稀疏 MoE 文本-图像到视频模型 StrucPhysVideo-TI2V，并通过逐步提高物理数据比例来兼顾通用视频生成与物理预测，在 Physics-IQ Verified 上获得 45.5% 得分。随后，作者引入 StrucPhysVideo-IA2V，将机器人末端执行器动作编码为条件，并通过动作注入、因果自回归扩散训练、因果 ODE 初始化和非对称分布匹配蒸馏，将双向视频模型转化为可流式生成的少步模型。该模型每个片段仅需四步去噪，并在 AgiBot 数据上的视觉保真度、轨迹一致性、深度一致性和交互质量方面优于所比较的基线。

## 核心贡献

1. 提出面向物理交互的视频清洗与整理流程，结合镜头边界检测、运动感知窗口选择、技术质量检查、内容纯度过滤和多模态物理验证。 2. 提出结构化物理 caption 与标签体系，分别描述场景动力学、相机与光照、世界知识与材料属性，以及带时间戳的实体行为，并将相机运动与物体运动区分开。 3. 提出 StrucPhysVideo-TI2V：基于冻结的 Qwen3-VL 条件编码器和 Wan VAE、稀疏 MoE 时空 Transformer、首帧约束流匹配以及物理数据课程训练的视频生成模型。 4. 提出 StrucPhysVideo-IA2V：使用因果动作编码器和逐块 AdaLN/交叉注意力将机器人末端执行器轨迹注入视频生成。 5. 设计三阶段因果化与少步蒸馏流程，将双向模型转化为因果自回归生成器，并通过因果 ODE 蒸馏和非对称 DMD 支持低延迟增量式 rollout。 6. 在 Physics-IQ Verified 上取得 45.5% 得分，并通过 caption 消融验证物理导向监督的收益；在机器人视频评测中提升了视觉保真度、动作轨迹一致性和交互质量。

## 与课题的关系

与研究重点高度相关。首先，StrucPhysVideo-TI2V 直接面向视频生成和视频扩散/流匹配建模，使用首帧条件、稀疏 MoE 时空 Transformer 和结构化物理监督来预测后续场景演化。其次，StrucPhysVideo-IA2V 是动作条件视觉世界模型，输入机器人末端执行器轨迹，预测动作导致的视觉结果，明确服务于闭环交互和具身模拟。第三，其因果动作编码器、因果注意力、按时间块的自回归 rollout 以及训练时自生成历史，涉及因果和流式长时序生成。第四，四步去噪、因果 ODE 蒸馏和非对称 DMD 直接对应实时生成、扩散蒸馏和降低推理延迟；稀疏 MoE 则与稀疏计算相关。论文还将延长时域流式 rollout、保持长期物理一致性、进一步降低到一至两步生成作为未来方向，但没有讨论显式缓存复用或稀疏注意力缓存机制。

## 局限 / 待核实

论文明确指出，当前模型仍需扩展到更长时域的流式 rollout，并在长期生成中保持物理一致性；推理延迟仍需进一步降低，目标是从四步生成推进到一至两步。论文还指出需要支持更丰富的动作空间，并实现不同机器人平台之间的跨具身泛化。现有动作条件实验主要基于特定 AgiBot 数据和末端执行器目标位姿表示，跨平台、跨动作表示能力有限。评测主要依据 Physics-IQ Verified、AgiBot 视频离线指标和选定的定性结果，论文未展示真实机器人闭环控制或在线部署结果。TI2V 训练使用私有采集的视频数据，数据规模、筛选偏差及其对泛化性的影响未被充分量化。论文未明确说明缓存复用机制、超长视频生成能力以及在真实环境中长期闭环稳定性的结果。
