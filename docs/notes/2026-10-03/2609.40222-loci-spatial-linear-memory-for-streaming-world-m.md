# LOCI: Spatial Linear Memory for Streaming World Models

- **日期**：2026-10-03
- **评分**：75/100
- **作者**：Ji Xia, Tingting Liao, Xuezhi Liang et al.
- **方向**：World Models
- **论文**：[arXiv 2609.40222](http://arxiv.org/abs/2609.40222v1)
- **代码**：未开源

## Abstract 中文翻译

当摄像机重新访问之前观察过的区域时，视频世界模型应当重现那里原有的内容。这既需要记住过去的观测，也需要针对当前视点检索正确的观测。键值缓存能够保留视觉细节，但会随着视频长度增长；循环记忆较为紧凑，却会将历史压缩到固定大小的状态中，使得单个过去观测无法再被直接访问。我们提出LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的Transformer模块中，主注意力保留过去观测的键值缓存；在另一半模块中，主注意力被限制在当前块内，并辅以循环线性注意力记忆，其读写由投影摄像机几何条件化，因此视点同时参与记忆寻址和存储内容的形成。循环读出结果会流入后续由缓存支持的模块，并为这些模块的查询提供累积的场景上下文。在公开的MIND记忆基准和留出的录制轨迹上，与具有代表性的世界模型以及采用相同方案训练的全Softmax模型相比，LOCI能够更忠实地重现重新访问的内容；在使用完整历史时，在相同长度下，其峰值内存相比全Softmax降低约30%。在使用有界的保留观测库时，LOCI能够以恒定内存生成长视频，并且在相同预算下比全Softmax更加忠实。

## 全文总结

论文提出LOCI，一种面向流式视频世界模型的混合空间记忆架构，将带摄像机几何条件的循环线性记忆与显式历史键值缓存结合起来。循环状态以固定大小累积完整历史并帮助后续注意力定位相关观测，缓存则保留可直接访问的视觉细节。LOCI采用分块因果生成、按块进行保留、以及由近期窗口和多样视图库组成的有界历史访问机制。在5B Wan骨干网络上，LOCI在MIND记忆基准、留出的虚幻引擎轨迹和长程回访测试中改善了场景回访一致性；在相同有界KV预算下优于同配方全Softmax模型，并能以恒定内存生成300秒视频。分析表明，循环状态能够编码摄像机姿态，且其读出确实改善了历史注意力对共视内容的检索。

## 核心贡献

1. 提出LOCI混合空间记忆架构，将投影几何条件化的循环记忆与直接历史KV访问结合，使循环上下文能够影响历史查询，同时保留观测级视觉细节。其按块而非按令牌执行通道保留，使遗忘速度对应经过的视频时间。\n2. 将贯穿完整历史的固定大小循环状态与固定容量的观测库结合，支持有界内存的流式生成。在相同有界KV预算下，相比同配方全Softmax模型，MIND记忆测试的整段PSNR提升0.89 dB，并在50个片段中的44个片段上更优。\n3. 在公开MIND基准上进行零样本评估，LOCI的MSE、PSNR和SSIM优于论文中报告的GIM-World结果；在长程回访和留出轨迹上也表现出更好的场景恢复能力。\n4. 通过消融和分析验证循环状态、投影摄像机编码以及循环读出对短程和长程回访一致性、摄像机姿态解码和历史注意力定位的作用。\n5. 在完整历史模式下，相同长度的峰值内存较全Softmax降低约30%；在有界稀疏历史模式下，以恒定内存完成300秒生成。

## 与课题的关系

论文与研究重点高度相关。它直接研究摄像机控制的视频世界模型、动作或摄像机轨迹条件生成、场景回访一致性和闭环式长时程视觉模拟。其核心方法结合循环线性注意力、显式KV缓存、稀疏历史访问和缓存复用，解决了流式及长视频生成中历史信息的压缩、检索和内存增长问题。按块更新状态、固定容量观测库以及半数注意力层改用固定状态，有助于实现常数内存的长视频生成；在完整历史下约30%的内存节省和有界模式下的恒定内存，直接对应实时生成与高效推理目标。不过论文没有主要围绕蒸馏或严格实时帧率展开，且其速度优势部分依赖优化实现。

## 局限 / 待核实

论文明确指出：留出轨迹是在Unreal Engine中渲染的，没有评估真实世界采集数据；所有模型的绝对保真度仍然较低，基准平均PSNR低于15 dB，因此结果主要应理解为相对改进；实验只使用一个5B骨干网络和较短的5,000步微调预算；按令牌保留机制的比较使用了在短程比较之后定义的扩展指标；所有模型在全部30个模块中都保留显式历史摄像机注意力分支，因此循环路径只减少了一半主注意力KV，而不是全部历史存储；训练时循环状态由带噪块特征构建，而推理时则由生成块提交；有界稀疏模式下与全Softmax的速度持平依赖于优化后的循环分支实现。此外，论文未明确说明在真实机器人闭环控制、严格实时延迟、不同规模骨干网络、蒸馏方法或更长训练预算下的表现。
