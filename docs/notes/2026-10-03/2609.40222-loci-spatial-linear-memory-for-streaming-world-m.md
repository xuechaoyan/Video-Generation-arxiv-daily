# LOCI: Spatial Linear Memory for Streaming World Models

- **日期**：2026-10-03
- **评分**：75/100
- **作者**：Ji Xia, Tingting Liao, Xuezhi Liang et al.
- **方向**：World Models
- **论文**：[arXiv 2609.40222](http://arxiv.org/abs/2609.40222v1)

## Abstract 中文翻译

当摄像机重新访问此前观察过的区域时，视频世界模型应当重现那里原有的内容。这既要求记住过去的观测，也要求针对当前视角检索正确的观测。键值缓存能够保留视觉细节，但会随着视频长度增长；循环记忆虽然紧凑，却会将历史压缩到固定大小的状态中，使单个过去观测无法再被直接访问。我们提出LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的Transformer模块中，主注意力保留过去观测的键值缓存；在另一半模块中，主注意力被限制在当前块，并配合一种循环线性注意力记忆，其读写由投影相机几何条件化，使视角同时参与记忆寻址和存储内容的形成。循环读取结果会传递到后续由缓存支持的模块中，为其查询提供累积的场景上下文。在公开的MIND记忆基准和保留的录制轨迹上，与具有代表性的世界模型以及采用相同训练方案的全Softmax模型相比，LOCI能够更加忠实地重现被重新访问的内容；在使用完整历史时，在相同长度下其峰值内存相较全Softmax降低约30%。在使用有界的保留观测库时，LOCI能够以恒定内存生成长视频，并且在相同内存预算下比全Softmax更加忠实。

## 全文总结

LOCI面向需要长期空间一致性的视频世界模型，将两种记忆结合起来：由相机几何条件化的固定大小循环Kimi Delta Attention状态，以及保存观测级视觉细节的历史键值缓存。模型以五帧为块进行因果生成，在15个模块中使用循环记忆和块内注意力，在另外15个模块中使用历史Softmax注意力；循环读取结果会影响后续历史注意力的查询，从而帮助模型定位与当前视角相关的旧观测。通过按块保留、近期窗口和基于视场覆盖的旧视图库，LOCI支持有界内存的长视频流式生成。基于5B Wan骨干网络的实验显示，LOCI在MIND记忆基准、保留轨迹和与全Softmax的受控比较中均改善重访一致性；有界模式可在恒定内存下生成300秒视频。

## 核心贡献

1. 提出混合空间记忆架构，将投影相机条件化的循环记忆与可直接访问历史细节的键值缓存结合，使循环上下文能够塑造历史注意力查询，同时保留观测级信息。2. 在循环记忆中采用逐 token 的增量更新和逐块 retention，使遗忘频率对应经过的视频时间而非光栅 token 顺序。3. 设计固定容量的旧视图库、近期窗口和循环状态相结合的有界流式方案；在相同键值预算下优于同配方全Softmax模型，并支持恒定内存的长视频生成。4. 在MIND基准和保留的Unreal Engine轨迹上验证了重访保真度、长期召回、局部一致性和资源效率方面的改进；完整历史下相同长度的峰值内存约降低30%。

## 与课题的关系

该论文直接涉及视频生成、视频扩散、动作或相机条件化世界模型、闭环式长时程模拟，以及流式和长视频生成。其核心问题是摄像机离开场景后再次返回时保持空间和外观一致性；PRoPE将投影相机几何注入循环记忆，使视角参与历史内容的读写和寻址。块因果扩散生成支持按时间推进的交互式世界模型，有界键值库与固定大小循环状态支持恒定内存的长序列流式生成。通过减少一半主历史注意力层、使用固定状态压缩远程历史，模型还降低了内存增长；论文未涉及蒸馏或稀疏注意力训练，但其有界历史访问和记忆复用与稀疏访问、缓存复用方向相关。

## 局限 / 待核实

论文明确指出：实验中的保留轨迹由Unreal Engine渲染，未评估真实世界采集视频；所有模型的绝对保真度仍较低，基准平均PSNR低于15 dB；实验只研究了一个5B骨干网络和较短的5000步微调预算；逐 token retention 的比较使用了在短期比较之后定义的扩展指标；所有模型在30个模块中都保留显式历史相机注意力分支，因此循环路径只减少了一半主注意力的历史KV，而不是全部历史存储；训练时循环状态由带噪块特征构建，推理时则由生成块提交；有界稀疏模式与全Softmax的速度持平依赖于优化后的循环分支实现。论文未明确说明真实部署中的闭环控制性能、蒸馏效果以及在更大模型或更长训练下的表现。
