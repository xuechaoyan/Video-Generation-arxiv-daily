# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **日期**：2026-11-07
- **评分**：74/100
- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models
- **论文**：[arXiv 2611.07867](http://arxiv.org/abs/2611.07867v1)
- **代码**：未开源

## Abstract 中文翻译

构建一个可游玩的世界不仅需要生成逼真的视频，还需要响应式控制、持久的空间结构，以及与动态实体之间连贯的交互。将生成帧作为唯一的循环世界表示，会使这些要求依赖于视角相关的外观合成，从而难以在生成和交互过程中维持长期的空间与时间一致性。我们提出 PlayGen2，这是一个将学习到的三维状态演化与神经渲染分离的实时交互式世界模型。PlayGen2维护一个持久化世界记忆，其中包括以体素占用网格表示的静态几何结构，以及为玩家和其他实体建立的、按身份索引的三维状态。在固定大小的局部区域内，其世界状态模型联合学习以动作条件化的实体动力学、几何补全和实体发现，并将更新提交到持久化世界记忆中。一个独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观察，而不会将生成图像反馈到状态预测中。以 Doom 为测试平台，我们证明该模型能够学习世界动力学，包括具有几何感知能力的玩家运动以及玩家与非玩家角色之间的交互。在配备 M4 Pro 芯片的 MacBook Pro 上，完整的模拟与渲染流程后端延迟约为 160 毫秒，说明该框架具有较高的计算效率。除单人交互外，我们还展示了在未见过的 Doom 地图上的零样本部署、通过组合单人模型实现多人交互，以及通过基于规则的状态干预实现可编程游戏玩法。这些能力体现了所学习游戏世界模型的可迁移性与可扩展性。代码和预训练模型权重已公开。

## 全文总结

PlayGen2提出一种显式三维状态驱动的可游玩世界模型，将世界模拟与视频渲染解耦。模型以持久化体素几何和按身份索引的实体状态作为世界记忆，在玩家中心的局部区域内根据动作预测实体动力学、补全未知几何并发现新实体；独立的扩散渲染器再依据深度、语义投影和有限RGB历史生成第一人称画面。基于Doom的实验表明，该方法能够维持长时域控制和视觉生成，支持未见地图、多人组合及规则化状态干预，并在消费级笔记本上达到交互式运行速度。

## 核心贡献

1. 提出显式三维世界状态框架，以体素占用几何和按身份索引的实体状态统一表示世界，并联合学习几何补全、实体发现和动作条件化动力学，将更新写入持久化世界记忆。2. 提出与状态演化分离的状态条件神经渲染流程，使生成图像不再反馈到世界状态预测，并在Doom中实现几何感知的玩家运动和玩家—NPC交互。3. 展示模型在未见Doom地图上的零样本迁移、单人模型组合形成的多人交互，以及无需重新训练的可编程游戏机制。4. 在M4 Pro MacBook Pro上实现完整模拟—渲染流程约160毫秒后端延迟；8步去噪时串行约4.98 FPS，重叠执行约7.16 FPS。

## 与课题的关系

该工作直接对应动作条件视觉世界模型、闭环交互模拟和实时视频生成方向。它用显式持久化三维状态替代纯生成帧循环，有助于缓解长视频或长时域闭环探索中的几何漂移、实体漂移和重访不一致问题；动作条件状态转移支持玩家控制及离屏NPC持续演化。其独立扩散渲染器仍属于视频生成模块，但RGB历史只用于渲染，避免视觉自回归误差直接污染状态预测。固定大小局部更新、共享特征复用以及少步扩散渲染与实时延迟测评，也与稀疏计算、缓存复用和交互式生成密切相关。

## 局限 / 待核实

论文的实验主要基于Doom，训练数据仅来自Freedoom2 MAP01上的约500小时规则控制器轨迹，跨游戏和更复杂开放环境的泛化能力尚未验证。未见地图上的渲染沿用训练得到的Freedoom2视觉风格，深度和语义条件无法提供原生纹理，因此参考指标会受到外观差异影响。模型在固定大小的玩家中心局部区域内运行，局部区域之外的实体虽被存储但不会持续模拟。状态转移阶段不使用运行时碰撞校正；NPC追踪实验在200步内的成功率为55%，说明实体动力学仍不完美。系统在M4 Pro上的串行速度约为4.98 FPS，且平均后端延迟约200.6毫秒（重叠执行时约275.7毫秒），因此其“实时”性能仍属于交互式而非高帧率视频生成。论文未明确说明更大规模场景、更长时间尺度或更丰富动作空间下的性能上限。
