# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models

## Abstract 中文翻译

构建一个可游玩的世界不仅需要生成逼真的视频，还要求具备响应式控制、持久的空间结构，以及与动态实体进行连贯交互的能力。将生成帧作为唯一循环世界表示，会把这些要求与依赖视角的外观合成绑定在一起，从而难以在生成和交互过程中维持长期的空间与时间一致性。我们提出 PlayGen2，一种实时交互式世界模型，将学习到的三维状态演化与神经渲染分离。PlayGen2维护持久的世界记忆，其中静态几何由体素占用网格表示，玩家及其他实体则由按身份索引的三维状态表示。在固定大小的局部区域内，其世界状态模型联合学习动作条件下的实体动力学、几何补全和实体发现，并将更新提交到持久的世界记忆中。独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观测，而不会将生成图像反馈到状态预测中。我们以《Doom》为测试平台，展示了该模型能够成功学习包括几何感知的玩家运动以及玩家与非玩家角色交互在内的世界动力学。该框架具有较高的计算效率，在配备 M4 Pro 芯片的 MacBook Pro 上，完整的模拟与渲染流程后端延迟约为 160 毫秒。除单人交互外，我们还展示了在未见过的《Doom》地图上的零样本部署、通过组合单人模型实现多人交互，以及通过基于规则的状态干预实现可编程游戏玩法。这些能力体现了所学习游戏世界模型的可迁移性和可扩展性。代码和预训练模型权重均已公开。

## 全文总结

PlayGen2提出一种将显式三维世界状态演化与神经渲染分离的实时可玩世界模型。模型以持久世界记忆保存体素几何和按身份索引的动态实体，在玩家中心的固定局部区域内，根据动作、历史状态和几何上下文联合完成未知几何、发现新实体并预测实体动力学；随后由扩散渲染器依据深度、语义投影和有限 RGB 历史生成第一人称画面，生成图像不参与状态预测。基于约500小时、单张 Freedoom2 地图上的训练，实验显示模型能够进行几何感知的移动、玩家-NPC交互、长时域控制和视觉生成，并可迁移到未见地图、组合为多人交互系统及支持规则化状态干预。完整流程在 M4 Pro MacBook Pro 上达到约 5 FPS，重叠执行时约 7.16 FPS。

## 核心贡献

1. 提出基于显式三维状态的可学习世界框架，以体素占用几何和身份索引实体状态构成持久世界记忆，并在局部区域内联合学习几何补全、实体发现和动作条件动力学。 2. 将世界状态模拟与神经渲染解耦：世界状态模型负责持续演化和记忆更新，扩散渲染器根据状态投影生成视觉观测，避免生成图像误差递归污染状态预测。 3. 在《Doom》上实现实时可玩模拟，学习几何感知的玩家运动及玩家-NPC交互，并在长时域和未见地图上展示控制与生成能力。 4. 利用显式状态接口实现无需重新训练的多人模型组合和可编程游戏规则干预。 5. 在消费级笔记本上实现具有较低延迟的完整模拟-渲染流程。

## 与课题的关系

论文与视频生成和视频扩散高度相关：其独立渲染器采用潜空间扩散 Transformer，根据显式三维状态、深度/语义条件、动作和 RGB 历史生成视频帧。它直接研究动作条件视觉世界模型、闭环交互和长视频生成，并通过持久世界记忆解决仅依赖生成帧时容易出现的空间不一致、实体漂移和误差累积问题。其固定大小局部状态更新、状态与渲染解耦、历史帧丢弃训练以及 8 步去噪和并行执行，分别涉及稀疏局部计算、缓存/历史复用、扩散加速和实时生成。模型还支持视野外实体持续演化、未见地图零样本探索及多人组合，体现了面向可控模拟和闭环世界建模的扩展性。

## 局限 / 待核实

论文的训练数据仅来自 ViZDoom 中 Freedoom2 MAP01 的约500小时单图、规则控制器轨迹，训练分布和环境类型较为有限。实验主要在《Doom》及其地图上进行，尚未证明对更复杂、更开放或真实世界环境的泛化能力。完整流程仍存在约200.6毫秒串行后端延迟和约4.98 FPS吞吐，尚未达到通常意义上的高帧率实时视频生成。NPC追踪实验在200步内的成功率为55%，说明动态实体行为仍不完全可靠。系统不执行运行时碰撞校正，可能导致状态或交互误差。局部初始化时缺少唯一的姿态对齐真实参考，视觉评估主要使用 FID/FVD，且未见地图的参考指标同时受到纹理风格差异影响。模型依赖显式结构化游戏状态和特定投影表示，论文未明确说明其在缺少此类状态标注或传感器信息时的适用性。
