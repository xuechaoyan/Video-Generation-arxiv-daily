# TempoKV: Predictive KV Cache Quantization for Autoregressive Video Generation

- **日期**：2026-10-14
- **评分**：79/100
- **作者**：Jiahui Hu, Weile Mo, Peiliang Cai et al.
- **方向**：Video Generation, Autoregressive and Streaming Video
- **论文**：[arXiv 2610.15324](http://arxiv.org/abs/2610.15324v1)
- **代码**：未开源

## Abstract 中文翻译

自回归（AR）视频扩散模型能够流式生成长视频，但由于 KV 缓存快速增长而面临显著的内存开销。现有 KV 缓存量化方法主要针对大语言模型设计，难以直接迁移到视频模型，因为视频模型中的激活具有不同的统计特性和显著的时空冗余。我们观察到，视频 KV 缓存随时间变化具有很强的可预测性，并且存在明显的不对称性：键主要可以根据其时间历史进行预测，而值主要依赖当前键，并且只需要较短的先前值历史。基于这些观察，我们提出了 TempoKV，一种无需训练的、面向自回归视频生成的预测式 KV 缓存量化框架。TempoKV 根据键和值各自不同的依赖关系进行预测，并仅以低精度存储预测残差。两个预测器都十分轻量，仅通过在少量 BF16 样本上进行线性回归离线校准一次，并在不同提示词和生成过程中保持固定。在 Self-Forcing、Causal Forcing 和 LongCat-Video-13B 上的实验表明，在相当或更高的压缩比下，TempoKV 始终比现有 KV 缓存量化方法实现更高的生成质量；其 KV 缓存压缩比最高达到 6.71 倍，并取得了最佳的整体质量—效率权衡。我们的代码将发布在 GitHub 上。

## 全文总结

论文针对自回归视频扩散模型中随视频长度线性增长的 KV 缓存内存瓶颈，提出无需训练的 TempoKV 预测式量化方法。作者发现，键可由同一空间位置的历史键较好预测，而值主要依赖当前对齐的键，并辅以短值历史。因此，TempoKV分别预测键和值，只量化预测残差，并为键分配更高精度；预测器通过少量 BF16 轨迹离线线性回归校准。Self-Forcing、Causal Forcing 和 LongCat-Video-13B 实验显示，该方法在保持生成质量和长时序一致性的同时，实现最高 6.71 倍 KV 缓存压缩，降低峰值显存，并仅带来较小运行时开销。

## 核心贡献

1. 揭示视频 KV 缓存中键和值的非对称时序可预测性：键主要依赖自身历史，值则显著受当前对齐键的影响。\n2. 提出 TempoKV 预测式 KV 缓存量化框架，分别采用时间预测器和键到值的交叉预测器，仅对预测残差进行低比特量化。\n3. 设计非对称精度分配、锚定帧高精度量化及短历史上下文机制，并通过离线线性回归完成免训练校准。\n4. 在三种自回归视频生成模型和多种精度配置上验证了方法的有效性，在较高压缩比下取得更好的视频质量、显存效率和延迟权衡，最高达到 6.71 倍压缩。

## 与课题的关系

论文与研究重点高度相关，直接面向自回归、流式和长视频生成中的 KV 缓存内存瓶颈。它利用视频 latent 帧之间的时空冗余和缓存演化的可预测性，通过残差量化、非对称键值精度和缓存重用降低长上下文生成的存储需求。该方法尤其适合需要持续复用历史上下文的长视频和实时生成系统；实验还表明其可在减少峰值显存的同时保持质量，并仅引入约 11.9% 的生成开销。不过，论文主要解决 KV 缓存压缩，而非视频生成模型本身的蒸馏、稀疏注意力或闭环动作条件建模。

## 局限 / 待核实

论文将实验主要限制在 Self-Forcing-Wan-1.3B、Causal Forcing-Wan-1.3B 和 LongCat-Video-13B，以及 MovieGen 提示词和特定分辨率、帧数设置，尚未证明对更广泛模型、任务和硬件的普适性。预测器需要使用 BF16 校准轨迹进行离线拟合，且仍需保留锚定帧和预测所需的历史信息。值使用过低精度（例如 1 bit）会导致生成质量显著崩溃，压缩与质量之间仍存在权衡。解码压缩缓存会增加延迟，且论文未报告真实部署环境下的端到端吞吐、能耗或多用户场景表现。论文未明确说明代码发布后的可复现性和对不同提示分布、超长生成范围的稳定性。
