# TempoKV: Predictive KV Cache Quantization for Autoregressive Video Generation

- **日期**：2026-10-14
- **评分**：79/100
- **作者**：Jiahui Hu, Weile Mo, Peiliang Cai et al.
- **方向**：Video Generation, Autoregressive and Streaming Video
- **论文**：[arXiv 2610.15324](http://arxiv.org/abs/2610.15324v1)
- **代码**：未开源

## Abstract 中文翻译

自回归（AR）视频扩散模型能够流式生成长视频，但由于 KV 缓存快速增长而面临显著的内存开销。现有 KV 缓存量化方法主要针对大语言模型设计，迁移到视频模型时效果不佳，因为视频模型中的激活具有不同的统计特征和强烈的时空冗余。我们观察到，视频 KV 缓存随时间具有很强的可预测性，并呈现明显的不对称性：键可以根据其时间历史高度准确地预测，而值主要依赖当前键，并且只需要较短的前序值历史。基于这些观察，我们提出 TempoKV，一种面向 AR 视频生成的免训练预测式 KV 缓存量化框架。TempoKV 根据键和值各自不同的依赖关系进行预测，并仅以低精度存储预测残差。两个预测器都很轻量，仅通过在少量 BF16 样本上进行线性回归离线校准一次，并在不同提示词和生成运行之间保持固定。在 Self-Forcing、Causal Forcing 和 LongCat-Video-13B 上的实验表明，在相当或更高压缩比下，TempoKV 始终比现有 KV 缓存量化方法实现更高的生成质量；其 KV 缓存压缩比最高达到 6.71 倍，并取得了最佳的整体质量—效率权衡。我们的代码将发布在 GitHub 上。

## 全文总结

论文针对自回归视频扩散模型中 KV 缓存随视频时长线性增长、严重占用 GPU 内存的问题，提出免训练的 TempoKV 预测式量化方法。作者发现，键缓存能够由同一空间位置的历史键有效预测，而值缓存的主要预测信号是当前对齐的键，历史值仅提供有限补充信息。TempoKV 先预测并量化键残差，再利用重建的当前键和历史值预测并量化值残差，同时为键分配更高精度。预测器通过少量 BF16 校准轨迹离线线性回归得到，无需重新训练模型。其在三种自回归视频模型上的实验显示，TempoKV 在视觉质量、长时一致性、压缩率、显存和延迟之间取得了优于基线的平衡，最高实现 6.71 倍 KV 缓存压缩，并支持约 90 秒的长视频生成。

## 核心贡献

1. 揭示视频 KV 缓存中键和值的非对称时序预测关系：键主要依赖自身历史，值则显著受当前对齐键的影响，并通过分层及时序分析验证该规律。2. 提出 TempoKV 预测式残差量化框架，分别预测键和值，仅量化低幅度残差，并采用键高精度、值低精度的混合位宽分配。3. 设计轻量、免训练的离线线性回归校准方法，预测器可跨提示词和生成运行复用。4. 在 Self-Forcing、Causal Forcing 和 LongCat-Video-13B 上验证方法有效性，在最高 6.71 倍压缩下保持较高生成质量，并降低 KV 缓存和峰值显存开销。5. 通过交叉预测器、混合位宽和历史长度消融实验，验证了键到值预测、较高键精度以及短值历史和较长键历史的设计。

## 与课题的关系

论文与研究重点高度相关。它直接面向自回归、流式和长视频生成中的 KV 缓存瓶颈，通过利用跨潜在帧的时序冗余压缩历史上下文，降低长时生成所需的显存。方法无需训练，在线解码仅引入较小延迟，适合实时或近实时生成优化；在 Self-Forcing、Causal Forcing 等因果视频生成框架上的验证也与闭环、持续上下文复用密切相关。论文重点是缓存量化和预测式残差编码，而不是动作条件建模、世界模型或闭环控制本身。

## 局限 / 待核实

论文是预印本，且实验主要基于 Self-Forcing-Wan-1.3B、Causal Forcing-Wan-1.3B 和 LongCat-Video-13B，以及 MovieGen 的前 128 个提示词，模型和数据覆盖范围有限。预测器需要离线收集 BF16 校准轨迹，并依赖训练模型中稳定的空间索引和跨帧统计规律，其对其他架构、任务或分布外提示词的泛化能力未被充分验证。实验主要考察 KV 缓存压缩对生成质量、显存和延迟的影响，没有系统报告端到端实时帧率或更广泛的硬件结果。极低精度下性能可能明显下降：值使用 1 bit 时质量显著崩溃。论文未明确说明代码发布后的可复现性、不同校准集规模的敏感性，以及在动作条件视觉世界模型或闭环交互场景中的表现。
