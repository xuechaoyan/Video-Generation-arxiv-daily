# WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

## Abstract 中文翻译

视频世界模型支持对动态环境进行交互式探索，但难以在长时间跨度和跨视角条件下遵循既有观测。我们提出WorldCrafter，一种为此学习可由相机查询的隐式三维感知记忆的视频世界模型。其核心思想是，让请求的视角决定如何将多视角证据压缩到视频生成器有限的令牌预算中。记忆编码器和姿态条件读出模块与视频生成器联合训练，在去噪前将历史观测整合为一组固定的、针对目标视角的令牌，而无需显式的基于深度的对应关系。通过将该记忆与近期时间上下文及少步蒸馏相结合，WorldCrafter能够从单张输入图像或文本提示开始进行流式场景探索。在静态和动态场景上的实验表明，该方法在保持分钟级探索视觉质量的同时，显著提升了长时一致性和相机控制准确性。

## 全文总结

WorldCrafter是一种面向交互式长视频生成的相机可控自回归视频世界模型。它从历史视频潜变量和相机参数中构建隐式三维感知记忆，并通过目标轨迹引导的读出模块，将与当前视角相关的信息压缩为固定数量的DiT记忆令牌；同时结合近期上下文以保持可见运动的连续性。模型基于多来源真实和合成数据分阶段训练，并通过少步金字塔蒸馏实现实时流式推理。实验覆盖静态、动态和文本生成场景，结果显示其在长时回访一致性、相机控制和整体视觉质量方面优于所比较的方法；消融实验验证了联合优化、姿态引导读出和最大覆盖率历史检索的作用。

## 核心贡献

1. 提出用于视频世界模型的隐式三维感知记忆，将历史潜变量压缩为保留时空信息的紧凑表示，并在固定令牌预算下进行高效写入和读出。2. 将该记忆整合到相机可控的自回归视频生成中，通过目标姿态引导的记忆读出和最大覆盖率历史检索提升长时回访一致性与相机控制精度。3. 通过记忆编码器、视频DiT和读出模块的联合优化，使记忆表示适配生成器的令牌空间。4. 采用混合少步蒸馏构建实时交互系统，在保持视觉质量和主体跟随能力的同时达到4块GPU上16帧/秒的生成速度。

## 与课题的关系

该论文与研究重点高度相关：它直接研究视频扩散世界模型、动作或相机条件控制、闭环长时探索以及自回归和流式生成。相机轨迹作为条件输入，生成视频块并将其加入历史档案，再通过回访轨迹评估闭环一致性。隐式三维记忆避免保存完整历史或显式深度对应关系，以固定大小令牌支持长视频生成；最大覆盖率检索、近期上下文和目标视角查询共同实现跨视角记忆。少步蒸馏用于降低扩散采样成本并实现实时推理，记忆编码和读出的低延迟也有助于流式系统部署。

## 局限 / 待核实

论文明确指出，沿特别复杂或特别长的轨迹时，一致性仍可能崩溃；每个视频块都重新编码历史会带来额外延迟。作者提出可使用自回归流式记忆编码器，增量更新记忆状态以减少重复计算。此外，WorldCrafter依赖估计的相机姿态和有限数量的历史帧，且实验结论基于特定数据集、基准和比较方法；论文未明确说明其在更大规模真实交互环境、严重姿态估计误差或更复杂动态场景中的表现。
