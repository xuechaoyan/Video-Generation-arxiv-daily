# DeCoPrune: Efficient KV-Cache Pruning for Autoregressive Video Diffusion via Denoising Consistency

- **日期**：2026-10-07
- **评分**：84/100
- **作者**：Zeqi Xiao, Qingle Liu, Kaiwen Zhang et al.
- **方向**：Autoregressive and Streaming Video
- **论文**：[arXiv 2609.39096](http://arxiv.org/abs/2609.39096v2)
- **代码**：未开源

## Abstract 中文翻译

自回归视频扩散天然支持流式生成和交互式控制，但其 KV 缓存会随着生成历史不断增长。现有压缩策略要么使用固定窗口丢弃历史，要么通过局部注意力和相似度信号选择 token，无法直接衡量当前块相对于保留上下文是否提供了额外信息。我们提出 DeCoPrune，一种无需训练、将缓存压缩视为去噪一致性问题的方法。我们通过实验证实，去噪难度可以作为 token 长期保留价值的有效代理：步间预测与最终去噪结果差异较大的 token，往往携带了难以从保留上下文中预测的视觉证据。DeCoPrune 使用当前块 token 的中间干净预测与最终去噪值之间的差异来衡量其去噪难度，将高差异 token 保留在长期缓存中，并剪除低差异 token。为评估信息保留能力，我们提出 CMBench，其中包含 58 个时长约一分钟的生成或真实世界上下文片段，以及 116 个要求回忆先前观察到的特定物体或场景的 Reappear 或 Revisit 延续任务。在 LingBot World v2 上的实验表明，DeCoPrune 在剪除超过 85% 的历史 KV token 的同时，仍能保持接近 FullKV 的长程回忆能力，并将延续生成速度提升超过 4 倍；在相近预算下，它显著优于所评估的缓存压缩基线。这些结果表明，去噪一致性可以作为模型内在信号，在降低自回归推理成本的同时保留长程信息。项目主页为 https://decoprune.github.io。代码位于 https://github.com/DeCoPrune/CMBench，基准数据集位于 https://huggingface.co/datasets/Aoraku/CMBench。

## 全文总结

本文研究长上下文自回归视频扩散中的 KV 缓存增长问题，提出无需训练的 DeCoPrune。方法利用中间干净预测与最终去噪结果之间的 token 级差异判断历史视觉信息的重要性，保留高差异 token、剪除低差异 token，并结合近期窗口、RoPE 重索引和可选的注意力头专门化。作者同时提出 CMBench，通过 Reappear 和 Revisit 任务测试模型对历史物体与场景的长程视觉回忆。在 LingBot World v2 上，DeCoPrune 剪除约 85.43% 的历史 KV token，达到 6.489 FPS 和 4.14 倍加速，DINO 回忆分数为 0.6701，接近 FullKV 的 0.6803；其头专门化版本达到 0.6783。

## 核心贡献

1. 提出 DeCoPrune：一种基于上下文条件下步间到最终去噪差异的训练无关 KV 缓存剪枝方法，以模型内在信号衡量历史 token 的长期信息价值。2. 设计物理缓存压缩机制，使用共享 token 掩码跨层收集并压缩 KV，同时保留初始 sink 块和最近窗口；在线评分复用正常去噪轨迹，无需额外模型评估或训练。3. 提出 CMBench，包含 58 个约一分钟的生成或真实视频上下文及 116 个 Reappear/Revisit 目标回忆任务，用于在受控历史 KV 压缩下评估长程视觉记忆。4. 通过实验表明，在超过 85% 历史 KV 剪枝和超过 4 倍延续生成加速下，方法仍保持接近 FullKV 的回忆能力，并在相近压缩预算下优于 Streaming、DummyForcing、ForcingKV、TempDiff 和随机选择等基线。

## 与课题的关系

与研究重点高度相关。该工作直接面向自回归、流式和长视频生成，通过物理剪枝历史 KV 缓存降低持续生成中的注意力和内存成本；在超过 85% 历史 token 剪枝下实现 4.14 倍延续生成加速，属于缓存复用与高效实时推理方向。其去噪一致性信号不依赖额外训练，可用于判断长程视觉证据是否已被上下文预测。CMBench 的 Reappear/Revisit 任务还评估了长视频生成中的历史场景和对象回忆能力。论文未直接研究动作条件世界模型或闭环动作控制，但其交互式、自回归视频延续机制可作为这类系统的高效上下文记忆组件。

## 局限 / 待核实

实验主要以 LingBot World v2 为主干模型，跨模型验证有限；对 LongLive 的额外测试仅包含 18 个、约 10 秒上下文的延续案例，因此方法在其他架构、更长时域或不同分辨率下的泛化能力仍不充分明确。CMBench 主要由 MiniMax H3 生成的 50 个上下文和 8 个真实世界上下文组成，共 116 个任务，规模和场景覆盖有限。评测主要依赖 OWL-ViT、SAM 2 和 DINOv2 的目标定位、分割与相似度，可能不能完整反映视频运动质量、物理真实性或复杂语义记忆。论文报告的剪枝率是生成过程中的累计历史 KV token 减少比例，不等同于峰值内存节省或总计算量；速度测试还排除了前缀处理。对已观察视频上下文进行压缩时，需要重新加噪并重新计算预测，相关预处理成本可能影响端到端收益。方法依赖高差异去噪 token 更具信息这一经验假设，极端压缩、分布外内容和需要精确保留低差异细节的场景下的可靠性仍有限。
