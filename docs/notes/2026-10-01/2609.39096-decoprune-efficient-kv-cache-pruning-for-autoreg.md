# DeCoPrune: Efficient KV-Cache Pruning for Autoregressive Video Diffusion via Denoising Consistency

- **日期**：2026-10-01
- **评分**：82/100
- **作者**：Zeqi Xiao, Qingle Liu, Kaiwen Zhang et al.
- **方向**：Autoregressive and Streaming Video
- **论文**：[arXiv 2609.39096](http://arxiv.org/abs/2609.39096v1)
- **代码**：未开源

## Abstract 中文翻译

自回归视频扩散天然支持流式生成和交互式控制，但其 KV 缓存会随着生成历史不断增长。现有压缩策略要么使用固定窗口丢弃历史，要么通过局部注意力和相似度信号选择令牌，但都没有直接衡量某个片段相对于保留上下文是否提供了额外信息。我们提出 DeCoPrune，一种无需训练的方法，将缓存压缩视为去噪一致性问题。我们发现，中间干净预测与最终去噪值之间差异较大的令牌，往往携带了难以从保留上下文中预测的视觉证据。DeCoPrune 使用这一模型内在信号，在长期缓存中保留高差异令牌，并剪除低差异令牌。为评估信息保留能力，我们提出 CMBench，其中包含 58 个约一分钟的生成或真实世界上下文片段，以及 116 个要求回忆早先事件或物体的 Reappear 或 Revisit 延续任务。在 LingBot World v2 上的实验表明，DeCoPrune 的 DINO 得分为 0.6701（取值范围为 0 到 1），累计历史 KV 令牌数量减少 85.43%，相较于 FullKV，延续生成速度提升 4.14 倍。其面向注意力头的专门化变体在 86.19% 的剪枝率下达到 0.6783，接近 FullKV 的 0.6803，并且在相近预算下超过所评估的压缩基线。这些结果表明，去噪一致性能够在降低自回归推理成本的同时，支持长期信息保留。项目主页为 https://decoprune.github.io。代码发布于 https://github.com/DeCoPrune/CMBench，基准数据集发布于 https://huggingface.co/datasets/Aoraku/CMBench。

## 全文总结

论文提出 DeCoPrune，一种无需训练的在线 KV 缓存剪枝方法，用中间干净预测与最终去噪结果之间的差异衡量令牌对长期视觉记忆的价值，并保留高差异令牌、剪除低差异令牌。作者同时提出 CMBench，通过一分钟级视频上下文中的物体重现和场景回访任务评估历史信息回忆。在 LingBot World v2 上，DeCoPrune 在大幅减少历史 KV 令牌的同时保持接近 FullKV 的上下文一致性，并显著提升延续生成速度。

## 核心贡献

1. 提出 DeCoPrune：基于上下文条件下中间到最终去噪差异的训练无关 KV 缓存保留准则，并通过物理压缩缓存减少后续注意力序列长度。 2. 提出 CMBench：包含 58 个约一分钟上下文和 116 个 Reappear/Revisit 延续任务的、面向历史视觉证据回忆的评测基准。 3. 通过主实验、消融实验和跨方法比较证明，去噪一致性选择在相近压缩预算下比随机、时间差分及其他缓存策略更能保留长期信息，同时降低延续生成成本。 4. 提供 RoPE 时间位置重索引和注意力头专门化变体，以改善远距离历史访问和压缩效率。

## 与课题的关系

该工作直接面向自回归和长视频扩散生成中的历史 KV 缓存增长问题，属于缓存复用、稀疏化和实时推理加速方向。它通过模型自身的去噪轨迹选择长期视觉证据，不需要额外训练、检索索引或显著性模型，适合流式生成和交互式延续。CMBench 的 Reappear/Revisit 任务还与长时记忆、闭环视觉世界模型中的历史状态保持相关，但论文主要研究视频生成缓存压缩，并未直接研究动作条件控制或闭环环境交互。

## 局限 / 待核实

实验主要以 LingBot World v2 为骨干模型，其他骨干模型的验证规模较小；论文未证明方法在更广泛的视频扩散架构和更长时间跨度上的普适性。CMBench 包含 50 个生成上下文任务和 8 个真实世界上下文片段，真实数据覆盖相对有限，且生成上下文使用 MiniMax H3 构造，可能限制结论的外部有效性。DINO 相似度主要衡量目标外观回忆，不能完整反映运动质量、因果一致性、物理真实性或事实准确性。论文报告的剪枝率衡量累计历史 KV 令牌减少量，而不是峰值内存节省或总计算量；同时，已观测上下文的前缀压缩需要额外的重新加噪和评估步骤。方法依赖可用的去噪轨迹和阈值、探测步等实现设置，论文未明确说明在不同噪声调度、模型结构或部署硬件上的调参成本。论文也未明确说明长期运行中的错误累积、极端压缩下的稳定性以及对动作条件闭环控制性能的影响。
