# UniWorld: A Unified World Model for Real-Time Visual World Simulation

- **方向**：Video Generation, World Models

## Abstract 中文翻译

连续视觉世界模拟需要将不断演化的场景几何与具有时间持久性的外观结合起来。我们提出 UniWorld，一个统一框架，在共享的视频生成模型中整合深度轨迹与参考外观。其核心设计在同一时间轴上维护视觉历史和几何历史。噪声对齐的重叠续接将已生成历史置于规定的采样噪声水平，并且只提交新生成的潜变量。滚动深度潜变量状态保留相应的几何控制，增量读取新获得的几何信息，并在每个采样窗口内保持条件不变。这些机制共同确保潜变量历史被精确保留，同时将活动深度状态限制在窗口大小以内。我们在多种场景类别上评估了连续生成、成对历史干预和长时域行为。同一个生成器支持估计深度、原生深度以及按需模拟器深度；缓存执行路径和增量执行路径能够产生逐位一致的输出。外观变化和几何控制分支通过同一接口运行，且不会修改已提交的历史。实测的稳态 DiT 执行路径达到了实时生成吞吐率，展示了 UniWorld 用于连续视觉世界模拟的效率。项目主页：https://zephipage.github.io/UniWorld。

## 全文总结

本文提出 UniWorld，用于将深度轨迹转换为连续、外观一致的视频世界模拟。方法以图像空间深度作为统一几何接口，以参考 RGB 和文本提供持久外观，通过噪声对齐的重叠续接保存视频历史，并通过滚动深度潜变量状态增量维护几何条件。实验覆盖驾驶、人类活动、模拟和合成场景，验证了多场景生成、历史干预、原生深度适配、长时域模拟以及缓存与在线执行的一致性。在八张 H100 GPU 上，DiT 稳态路径在 960×544 和 672×384 分辨率下分别达到 14.472 和 21.361 新帧/秒。

## 核心贡献

1. 提出 UniWorld 统一视觉模拟框架，将异构世界源转换为图像对齐深度，并与参考外观结合到共享的视频生成器中。2. 提出噪声对齐的重叠续接机制，在每个流采样时间步固定继承历史，仅提交新生成的视频后缀，从而实现精确的潜变量历史保留。3. 提出滚动深度潜变量状态，只读取新出现的深度位置，保留已提交观测对应的几何条件，并使活动几何状态与总序列长度无关。4. 建立统一的连续生成状态契约，并通过实际模型运行验证历史、深度、缓存和增量执行的一致性。5. 展示同一模型对估计深度、原生模拟深度和按需几何控制的支持，以及实时吞吐和长时域连续生成能力。

## 与课题的关系

论文与研究重点高度相关。它直接研究视频生成驱动的视觉世界模型和闭环式连续模拟接口：上游模拟器或世界源提供随时间变化的深度轨迹，生成器持续渲染视觉观测。其滚动状态、重叠窗口续接和增量读取机制对应长视频、流式生成和有限活动状态；噪声对齐历史投影用于避免跨窗口历史漂移；缓存与增量执行的逐位一致性涉及缓存复用和高效推理；经过 DMD 蒸馏的八步 DiT 路径面向实时生成。论文还支持控制分支和按需几何输入，但生成窗口内部仍采用双向处理，并非完全自回归的视频生成模型。

## 局限 / 待核实

论文明确的限制包括：实时吞吐率主要是稳态 DiT 与 Union 前向执行路径的测量，使用八张 H100 GPU，未明确给出完整端到端系统在常规硬件上的实时性能；活动深度状态的内存上界不包括临时副本、融合条件特征、模型激活、底层几何源存储以及不断增长的全局缓存；长时域实验包含不同来源集合，120 秒实验是训练集划分上的压力测试，因此不能完全代表未见数据上的泛化；实验主要依赖深度条件和参考图像，论文未明确说明对更复杂动作决策、真实闭环策略控制或多智能体交互的系统评估；模拟场景的保真度指标低于部分其他场景，且论文未明确说明其原因。对于更广泛的数据规模、模型扩展性和实际部署成本，论文未明确说明。
