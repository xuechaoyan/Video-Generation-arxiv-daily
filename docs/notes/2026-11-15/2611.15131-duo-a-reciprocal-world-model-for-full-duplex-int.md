# Duo: A Reciprocal World Model for Full-Duplex Interaction

## Abstract 中文翻译

本文介绍了互惠世界模型（Reciprocal World Model，RWM），并提出Duo v1——一种能够持续感知视听输入、同时实时回应用户的全双工世界模型。RWM认为，智能与物理现实同等构成“世界”的基本要素。现有世界模型主要关注对后者的模拟，将推理和决策留作外部控制，而非世界内在的一部分。在RWM中，我们确定了两种同等基础的能力：意图（Intent），为世界交互提供认知能力；实现（Realization），生成连贯的视听行为。为实现这一构想，Duo v1引入了三项关键技术设计：（1）采用自回归建模进行持续的交互推理和参与决策，而不是将其局限于扩散模型的指令理解；（2）在统一时间线上为意图模块和实现模块构建分块特定的条件与同步标记。模块特定的注意力掩码在块内和块间强制执行因果依赖，防止模型访问未来输入；（3）通过双重 rollout 蒸馏缓解两个模块中的分布偏移，在训练中使用自回归生成的意图标记以及由实现模块合成的视听历史。两个模块都持续感知实时音频、视频和文本，从而支持带有自发对话和打断的全双工交互。除对话外，用户还可以分享真实物体、重塑虚拟场景、指导助手，或在没有鼠标和键盘控制的情况下进行视听游戏。Duo v1的发布是我们的第一步，下一版本即将推出。我们期待对这一新兴领域开展更广泛的探索。

## 全文总结

论文提出互惠世界模型RWM，将世界建模从单纯模拟物理环境扩展为同时建模环境与其中的智能交互者。Duo v1由自回归多模态意图模块和因果视听实现模块组成：前者按约0.71秒的时间块持续决定说话或等待并生成文本，后者依据意图隐藏状态、用户视听输入、参考图像和历史媒体生成同步的语音与视频。系统通过统一时间线、跨块因果注意力、双重 rollout 蒸馏、四步生成、流式VAE解码以及KV缓存管理实现全双工实时交互。在30个案例、180项人工检查中总体通过率为93.3%，但内容响应性仅为73.3%。

## 核心贡献

1. 提出互惠世界模型RWM的概念，将Intent（交互认知与参与决策）和Realization（连贯视听行为生成）视为世界模型的两个核心组成部分。 2. 构建Duo v1模块化架构，以自回归多模态语言模型持续进行交互推理和说话/等待决策，并以因果联合视听扩散模型生成语音和视频。 3. 设计统一时间线上的分块条件、同步标记和模块特定因果注意力掩码，避免块内及块间的信息泄漏并保持长时连续性。 4. 提出双重 rollout 分布匹配蒸馏，使训练同时适应自回归生成的意图历史和实现模块自生成的视听历史，将生成压缩为四步流式过程。 5. 构建包含合成对话、录制对话和双流视听数据的数据流程，并设计支持持续输入、因果潜变量解码、GPU调度、KV缓存复用与定期重置的流式推理系统。

## 与课题的关系

与研究重点高度相关。该工作直接面向视频生成与视频扩散，使用因果联合视听扩散Transformer在连续时间块中生成视频和音频；其Realization模块依据用户视听输入、意图隐藏状态和历史生成媒体实现闭环交互，属于具有行动/参与决策能力的交互式视觉世界模型。系统采用自回归、因果分块和持续流式生成，支持用户在生成过程中继续输入并进行打断，契合长视频与闭环模拟方向。其四步分布匹配蒸馏、流式VAE解码、分块重叠调度以及Intent和Realization的KV缓存管理，直接涉及实时生成、蒸馏、缓存复用和推理加速。论文报告的单块处理延迟约为330–650毫秒，目标是将每个17帧块的周期控制在约708毫秒以内。

## 局限 / 待核实

论文明确指出Duo v1仍处于初步阶段，目前主要支持基础视听对话；更长会话中的响应时序和一致性、对误解的恢复能力仍需更广泛评估。人工评测仅包含30个实时双工交互案例，且内容响应性为73.3%（22/30），主要在需要结合语音、视频和语境推断用户真实意图时失败。音视频同步通过率为90.0%，情绪一致性为96.7%，仍存在改进空间。系统首个可见输出还可能受到最多约708毫秒的采样窗口等待影响，并依赖单台八GPU服务器维持持续生成。论文未明确说明更长时间尺度上的定量生成质量、与其他实时视频生成系统的全面对比，以及真实用户规模化部署成本。
