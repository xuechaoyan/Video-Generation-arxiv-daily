# LOCI: Spatial Linear Memory for Streaming World Models

- **日期**：2026-10-02
- **评分**：75/100
- **作者**：Ji Xia, Tingting Liao, Xuezhi Liang et al.
- **方向**：World Models
- **论文**：[arXiv 2609.40222](http://arxiv.org/abs/2609.40222v1)
- **代码**：未开源

## Abstract 中文翻译

当摄像机重新访问先前观察过的区域时，视频世界模型应当重现那里曾经存在的内容。这既需要记住过去的观测，也需要为当前视角检索正确的观测。键值缓存能够保留视觉细节，但会随着视频长度增长；循环记忆虽然紧凑，却会将历史压缩到固定大小的状态中，使单个过去观测不再能够被直接访问。我们提出 LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的 Transformer 模块中，主注意力维护过去观测的键值缓存；在另一半模块中，主注意力仅作用于当前片段，并辅以循环线性注意力记忆。该记忆的读写由投影相机几何条件化，使视角同时参与记忆寻址和存储内容。循环记忆的读出结果会传递到后续由缓存支持的模块中，使其查询能够利用累积的场景上下文。在公开的 MIND memory 基准和留出的录制轨迹上，LOCI 比具有代表性的世界模型以及采用相同训练方案的全 softmax 模型更忠实地重现重新访问的内容；在使用完整历史时，在相同长度下，其峰值内存相较全 softmax 降低约 30%。在使用有界的保留观测库时，LOCI 能够以恒定内存生成长视频，并且在相同内存预算下比全 softmax 更加忠实。

## 全文总结

LOCI 面向可控视频世界模型中的长期空间记忆与场景重访问题，将投影相机几何条件化的循环线性记忆与保留观测级细节的历史 KV 注意力结合起来。模型在部分层中使用固定大小的循环状态总结完整历史，在其余层中访问当前片段及保留的历史观测；循环读出会影响后续历史注意力的查询，从而帮助模型定位与当前视角相关的内容。基于 Wan2.2-TI2V-5B 的实验表明，LOCI 在 MIND memory 和留出的 Unreal Engine 轨迹上改善重访一致性，并在有界 KV 预算下优于同配方全 softmax 基线。完整历史模式下内存降低约 30%，有界稀疏历史模式可在恒定内存下生成 300 秒视频。不过，所有模型的绝对视觉保真度仍较低，且真实世界视频尚未被评估。

## 核心贡献

1. 提出混合空间记忆架构，将投影相机条件化的循环 Kimi Delta Attention 与直接历史 KV 访问结合，使循环上下文能够引导历史注意力查询，同时保留观测级视觉细节。 2. 设计按片段进行的 retention 和按 token 的 delta 更新，使遗忘频率对应视频时间而非光栅 token 顺序，并提升长间隔重访的局部一致性。 3. 将完整历史上的固定大小循环状态与固定容量的历史观测库结合，实现有界内存的流式长视频生成；在相同 KV 预算下，相比同配方全 softmax 模型取得更高 PSNR、更低 LPIPS 和更好的 MSE。 4. 在 MIND memory 基准和留出的录制轨迹上验证方法，在重访保真度方面优于多个世界模型及全 softmax 基线，并展示了完整历史模式的内存和可生成长度优势。

## 与课题的关系

论文与视频生成和视频扩散高度相关：它基于 chunk-wise diffusion forcing 和 Wan 视频 Transformer，进行动作或相机轨迹条件下的因果视频生成。它直接针对视频世界模型的闭环式长期模拟需求，解决摄像机离开场景后再次返回时的空间一致性和历史内容恢复问题。其核心技术与研究重点中的自回归、因果、流式和长视频生成相对应：模型按片段因果生成，循环状态跨片段累积，并通过有界观测库支持恒定内存的长时流式生成。它也涉及实时生成和效率优化，通过减少历史 KV 存储、使用线性循环记忆及局部注意力，在完整历史下将峰值内存降低约 30%；但有界模式下与全 softmax 的速度相同，实时性收益并不明确。论文还体现了稀疏注意力和缓存复用思想：历史 KV 仅保留近期窗口与具有覆盖多样性的观测库，而循环状态补充已丢弃观测的信息。

## 局限 / 待核实

论文明确指出：留出的轨迹主要由 Unreal Engine 渲染，未评估真实世界采集的视频；所有模型的绝对保真度仍较低，基准平均 PSNR 低于 15 dB；实验只使用一个 5B 骨干模型和较短的 5,000 步微调预算；per-token retention 的比较依赖于附加定义的扩展指标；所有 30 个模块仍保留显式历史相机注意力分支，因此循环路径只减少了主注意力 KV，而没有消除全部历史存储；训练时循环状态由带噪片段特征构建，而推理时则由生成片段提交，存在训练与推理状态来源差异；有界稀疏模式下与全 softmax 的速度相当依赖于特定的优化实现。此外，方法仍需要显式保留观测库，且被丢弃的观测不会被直接归档，只能依靠循环状态间接保留信息。论文未报告在更大规模模型、更多样真实场景或更长训练预算下的表现。
