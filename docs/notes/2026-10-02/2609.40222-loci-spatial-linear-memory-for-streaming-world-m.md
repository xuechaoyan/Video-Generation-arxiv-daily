# LOCI: Spatial Linear Memory for Streaming World Models

- **作者**：Ji Xia, Tingting Liao, Xuezhi Liang et al.
- **方向**：World Models
- **论文**：[arXiv 2609.40222](http://arxiv.org/abs/2609.40222v1)

## Abstract 中文翻译

当摄像机重新访问先前观察过的区域时，视频世界模型应当重现那里曾经存在的内容。这既要求记住过去的观测，也要求针对当前视点检索正确的观测。键值缓存能够保留视觉细节，但会随视频长度增长；循环记忆紧凑，却会将历史压缩进固定大小的状态，使单个过去观测无法再被直接访问。我们提出LOCI，一种同时保留这两类表示的混合空间记忆架构。在一半的Transformer模块中，主注意力保留过去观测的键值缓存；在另一半模块中，主注意力仅作用于当前块，并结合一种循环线性注意力记忆，其读写由投影相机几何条件化，使视点同时参与记忆寻址和存储内容的形成。循环读出结果流入后续的缓存支持模块，并为其查询提供累积的场景上下文。在公开的MIND记忆基准和留出的录制轨迹上，与具有代表性的世界模型以及采用相同训练方案的全Softmax模型相比，LOCI能够更忠实地重现重新访问的内容；在使用完整历史时，在相同长度下，其峰值内存相较于全Softmax降低约30%。在使用有界的保留观测库时，它能够以恒定内存对长视频进行流式生成，并且在相同预算下比全Softmax更加忠实。

## 全文总结

论文研究摄像机控制视频世界模型在长时间间隔后返回旧场景时的空间记忆问题。作者指出，纯键值历史缓存能保留细节但内存随时长增长，纯循环状态虽节省内存却会丢失可直接检索的观测。LOCI在30层Wan视频Transformer中交错使用15个带Kimi Delta Attention和PRoPE相机几何条件的循环记忆模块，以及15个保留历史KV的Softmax模块；循环读出通过特征流影响后续历史注意力的查询。模型采用五帧块因果生成、块级保留和可选的有界观测库，在MIND、Unreal Engine留出轨迹及录制轨迹上进行评估。LOCI在重访保真度方面优于外部世界模型和同配方全Softmax基线，在相同有界KV预算下MIND全片段PSNR提升0.89 dB，并能以恒定内存生成300秒视频；完整历史模式下，同长度峰值内存约降低30%。分析表明，循环状态能够编码相机朝向，并帮助历史注意力聚焦于当前视点可见的内容。

## 核心贡献

1. 提出LOCI混合空间记忆架构，将带投影相机条件的循环记忆与直接历史KV访问结合，使循环上下文能够引导历史查询，同时保留观测级视觉细节。 2. 将Kimi Delta Attention扩展到视频场景记忆：循环记忆逐token写入，并按视频块而非栅格token执行通道保留，使遗忘频率对应经过的视频时间。 3. 提出循环状态与固定容量观测库结合的有界流式方案；在相同KV预算下，相比同配方全Softmax模型取得更高的重访保真度，并支持恒定内存的长视频生成。 4. 在MIND记忆基准和留出轨迹上进行系统评估。LOCI在MIND上取得较低MSE、较高PSNR和SSIM；相较同配方全Softmax，在有界设置下PSNR提升0.89 dB，在完整历史设置下峰值内存约降低30%。 5. 通过消融和状态分析验证循环读出、PRoPE相机条件以及长程记忆对重访一致性和历史注意力定位的作用。

## 与课题的关系

与研究重点高度相关。LOCI直接面向视频生成中的动作或相机轨迹控制世界模型，并针对闭环探索中的场景重访和空间一致性设计记忆机制。其块因果生成方式支持自回归、流式和长视频生成；循环线性注意力提供固定大小的历史状态，保留KV和有界观测库则支持检索具体视觉细节。项目式相机编码使记忆读写依赖视点几何，有助于闭环模拟中的空间寻址。模型还通过减少历史Softmax层、使用稀疏保留库和循环状态来降低内存增长：完整历史下同长度内存约降低30%，有界模式下可恒定内存生成300秒视频。不过论文主要关注记忆与重访保真度，并未专门研究动作语义条件、实时端到端延迟或蒸馏。

## 局限 / 待核实

论文明确说明的局限包括：留出轨迹由Unreal Engine渲染，未评估真实世界采集数据；所有模型的绝对保真度仍较低，基准平均PSNR低于15 dB，因此结果主要应理解为相对改进；只研究了一个5B骨干网络和较短的5000步微调预算；逐token保留机制的比较使用了在短期比较之后定义的扩展指标；所有模型在30个模块中都保留显式历史相机注意力分支，因此循环路径只减少了一半主注意力KV，而不是全部历史存储；训练时循环状态由带噪块特征构建，而推理时由生成块提交；有界稀疏模式与全Softmax的速度相当依赖论文中的优化实现。论文未明确说明LOCI在更大模型、更多样真实环境、复杂动作条件或更严格实时延迟约束下的表现。
