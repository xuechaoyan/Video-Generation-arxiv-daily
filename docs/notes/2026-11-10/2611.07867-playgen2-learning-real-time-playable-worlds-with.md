# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **日期**：2026-11-10
- **评分**：74/100
- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models
- **论文**：[arXiv 2611.07867](http://arxiv.org/abs/2611.07867v1)
- **代码**：未开源

## Abstract 中文翻译

构建一个可游玩的世界不仅需要生成合理的视频，还要求具备灵敏的控制、持久的空间结构，以及与动态实体进行连贯交互的能力。将生成帧作为唯一的循环世界表示，会把这些要求都绑定到依赖视角的外观合成上，从而难以在生成和交互过程中维持长期的空间与时间一致性。我们提出 PlayGen2，一种将学习到的三维状态演化与神经渲染分离的实时交互式世界模型。PlayGen2维护一个持久化世界记忆，其中包括由体素占用网格表示的静态几何结构，以及为玩家和其他实体建立的、按身份索引的三维状态。在固定大小的局部区域内，其世界状态模型联合学习动作条件下的实体动态、几何补全和实体发现，并将更新提交到持久化世界记忆中。一个独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观测，而不会将生成图像反馈给状态预测过程。我们以 Doom 作为测试平台，证明该模型能够成功学习世界动态，包括具有几何感知能力的玩家运动以及玩家与非玩家角色之间的交互。在配备 M4 Pro 芯片的 MacBook Pro 上，完整的模拟与渲染流程后端延迟约为 160 毫秒，体现了该框架的计算效率。除单人交互外，我们还展示了其在未见过的 Doom 地图上的零样本部署、通过组合单人模型实现的多人交互，以及通过基于规则的状态干预实现的可编程游戏玩法。这些能力体现了所学习游戏世界模型的可迁移性和可扩展性。代码和预训练模型权重已公开。

## 全文总结

PlayGen2提出一种面向实时可游玩世界的显式三维状态建模框架，将世界状态演化与神经视频渲染分离。模型以持久化世界记忆保存体素几何、玩家状态和按身份索引的实体状态，在玩家中心的固定大小局部区域内，根据动作、历史和几何上下文预测实体运动、补全未知几何并发现新实体；随后将状态投影为深度和语义条件，由扩散渲染器生成第一人称视频，生成的RGB帧不再反馈到状态预测。基于仅在一个 Freedoom2 地图上训练的约500小时数据，模型能够进行具有碰撞意识的玩家移动、玩家-NPC交互、长时段探索和未见地图上的零样本世界扩展，并支持单人模型组合成多人交互及基于状态的规则干预。在M4 Pro笔记本上，串行运行约4.98 FPS、平均后端延迟200.6毫秒，重叠执行可达7.16 FPS。

## 核心贡献

1. 提出显式三维世界状态框架，以持久化体素占用网格和按身份索引的实体状态表示世界，并联合学习几何补全、实体发现和动作条件状态转移。 2. 将学习到的世界模拟与独立的状态条件神经渲染解耦，避免生成图像误差通过视觉历史反馈并累积到世界状态预测中。 3. 在Doom测试平台上实现几何感知的玩家运动、玩家-NPC交互、长期闭环探索和实时运行。 4. 展示未见地图零样本迁移、由单人模型组合实现的多人交互，以及无需重新训练的可编程状态干预。 5. 通过局部固定大小更新、持久化记忆和历史截断/扰动训练，提高了计算效率及对不完整或漂移历史的鲁棒性。

## 与课题的关系

该论文与研究重点高度相关。它是一个动作条件的视觉世界模型和闭环模拟系统：玩家动作驱动显式三维世界状态更新，状态再决定下一步观测和后续动作，支持长时间探索与实体交互。它采用独立的世界状态演化和扩散渲染，避免纯视频自回归表示在长期空间一致性、实体持久性和离视野动态方面的不足。方法还涉及实时生成与效率优化，包括固定大小局部计算、持久化世界记忆、状态与渲染解耦、RGB历史缓存，以及8步扩散采样。论文报告在消费级M4 Pro硬件上达到约4.98 FPS串行或7.16 FPS重叠执行，并实现约160至200.6毫秒级后端延迟，因此对实时生成、缓存复用和可扩展闭环世界建模具有直接参考价值。

## 局限 / 待核实

论文明确说明的局限包括：训练数据仅来自 Freedoom2 MAP01，且由规则控制器自动收集，训练分布较窄；未见地图上的外观仍主要呈现训练数据中的 Freedoom2 风格，深度和语义条件无法提供原生 Scythe 纹理，因此参考指标同时受到结构和外观差异影响；实体状态仅在当前局部三维区域内持续模拟，区域外实体不会被连续更新；系统不使用运行时碰撞校正，玩家和实体仍可能发生穿透；NPC追踪实验成功率为55%（200步内），并非所有交互都能成功；渲染和完整流程仍未达到高帧率实时视频，串行执行约4.98 FPS、平均后端延迟200.6毫秒。论文未明确说明更广泛游戏类型、复杂物理、多样视觉风格或更长时间尺度上的泛化能力。
