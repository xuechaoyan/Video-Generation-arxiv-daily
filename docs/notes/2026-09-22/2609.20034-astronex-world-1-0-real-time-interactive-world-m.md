# Astronex-World 1.0: Real-Time Interactive World Model Foundation

- **日期**：2026-09-22
- **评分**：74/100
- **作者**：Xin Zhou, Cong Miao
- **方向**：World Models
- **论文**：[arXiv 2609.20034](http://arxiv.org/abs/2609.20034v1)
- **代码**：未开源

## Abstract 中文翻译

我们提出 Astronex-World 1.0，一种开放的可控视频世界模型基础。给定文本提示（文生视频）或初始观测（图生视频）后，该模型能够在帧对齐的相机轨迹、连续动作和具身标识符条件下预测未来视觉状态，并接受插入到 rollout 指定位置的文本事件。该模型系列包含用于全上下文生成的双向模型，以及采用块因果注意力和跨块 KV 缓存、用于持续生成的因果模型；二者均建立在 Wan2.2-TI2V-5B 基础模型之上。PRoPE 注入相机内参和外参，64 维动作流则调制每个 Transformer 层。五阶段训练路径依次实现双向相机与动作控制，将骨干网络转换为块因果生成模型，蒸馏出少步学生模型，恢复混合域动力学，并采用非对称 DMD/DMD2 进行分布匹配。因果模型以 24 fps 生成 832×480 视频。全部五个训练阶段均可在两张 NVIDIA L20 48 GB GPU 上运行，因果模型则可在一张 GPU 上实时流式生成。该模型在 WBench Navi 和 WBench Full 上分别取得 73.5 和 70.0 分。在 Full 评测中，这一 5B 模型超过了 13.6B 的 LongCat-Video 和 14B 的 Helios，与 22B 的 LTX-2.3 仅相差不到 1 分，并超过了 YUME 1.5；后者同样基于 5B 基础模型、在 NVIDIA A100 GPU 上进行后训练。预留的动作输入和输出接口支持针对具身智能与自动驾驶进行后训练。

## 全文总结

Astronex-World 1.0 是基于 Wan2.2-TI2V-5B 构建的 5B 可控视频世界模型，提供双向离线生成和因果持续生成两种形式。模型通过 PRoPE 建模相机内外参，通过 64 维动作流和具身标识符实现逐层动作控制，并支持文本事件在指定时间点插入 rollout。其五阶段训练流程结合块因果注意力、KV 缓存、在线轨迹蒸馏、混合域 SFT 和 DMD/DMD2，使模型能够在单张 L20 上以 24 fps 实时生成 832×480 视频。模型在 WBench 上取得较高质量和一致性，但复杂交互、长时段漂移、物理真实性以及动作引起的主体运动仍存在明显不足。

## 核心贡献

1. 提出一个共享 5B 视频骨干的双向与因果模型家族，同时支持文生视频、图生视频、相机控制、连续动作控制和事件编辑。\n2. 设计统一控制接口：使用 PRoPE 注入相机内参与外参，以 64 维连续动作和具身 ID 调制全部 Transformer 层，并预留动作序列输出接口用于后训练。\n3. 提出五阶段训练方案，包括双向控制适配、块因果转换、在线 UniPC 轨迹蒸馏、混合域因果 SFT 和非对称 DMD/DMD2 分布匹配。\n4. 将块因果注意力、跨块 KV 缓存、局部历史窗口和持久注意力 sink 结合，实现实时、持续的视频生成。\n5. 在 WBench 和部分 VBench 评测中验证模型，并展示其在较低训练硬件成本下与更大规模开放模型竞争的性能。

## 与课题的关系

论文与视频生成和视频扩散高度相关：它直接建立在视频扩散 DiT 和流匹配框架上，并通过 UniPC 少步采样与 DMD/DMD2 蒸馏降低生成成本。其因果模型采用块因果注意力、跨块 KV 缓存、局部历史和注意力 sink，针对自回归、流式和长视频生成。相机内外参、连续动作和具身 ID 使其适用于动作条件视觉世界模型、闭环交互模拟、机器人和自动驾驶。模型在单张 NVIDIA L20 上以 24 fps 实时流式生成，直接对应实时生成研究方向；同时，滚动强制训练和自生成历史用于缓解自回归误差累积。

## 局限 / 待核实

论文明确指出：复杂交互能力较弱，当前文本切换接口难以表达多个独立的定时事件；长时段 rollout 仍会出现颜色偏移、场景变暗、结构重绘和细节丢失；DMD 蒸馏会抑制主体运动，导致生成结果偏静态；模型没有显式物理状态、深度、碰撞约束或三维场景表示，因此视频连贯性不等于物理准确性；64 维动作输入和动作输出接口仍需通过领域数据进行后训练。论文还报告 Full WBench 的 Interaction 分数仅为 47.6，Physical 分数为 68.1，部分 VBench 评测规模有限，且动态程度偏低。
