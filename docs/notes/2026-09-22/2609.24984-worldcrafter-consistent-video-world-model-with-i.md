# WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

## Abstract 中文翻译

视频世界模型能够支持对动态环境的交互式探索，但在长时间跨度和跨视角情况下，往往难以遵循先前的观测结果。我们提出 WorldCrafter，一种为此学习可由相机查询的隐式三维感知记忆的视频世界模型。其核心思想是，使所请求的视角决定多视角证据如何被压缩到视频生成器有限的令牌预算中。记忆编码器和姿态条件读出模块与视频生成器联合训练，在去噪之前将历史观测整合为一组固定数量、面向目标视角的令牌，而无需显式的基于深度的对应关系。通过结合这一记忆、近期时间上下文以及少步蒸馏，WorldCrafter 能够从单张输入图像或文本提示开始进行流式场景探索。在静态和动态场景上的实验表明，该方法在保持视觉质量的同时，显著提升了长时间跨度的一致性和相机控制准确度，并支持分钟级探索。

## 全文总结

本文提出 WorldCrafter，用于长时间、可交互视频生成的相机可控自回归视频世界模型。方法将历史潜在帧及其相机参数输入由预训练多视角三维表示初始化的记忆编码器，形成隐式三维感知表示；随后，姿态引导的读出模块根据即将执行的相机轨迹，从该表示中提取固定数量的记忆令牌，与近期时间上下文共同条件化视频 DiT。为控制计算量，系统保留最新帧并通过最大化目标区域联合视场覆盖来选择互补历史帧。模型在多个阶段进行训练，并通过少步金字塔蒸馏实现实时流式推理。实验在包含静态和动态场景、长达 528 至 1,648 帧且带闭环重访轨迹的基准上进行。WorldCrafter 在重访一致性和相机控制指标上优于比较方法；其快速版本达到 16 fps，并在分钟级探索中保持较好的视觉质量。消融实验表明，隐式三维感知记忆、记忆编码器与生成器的联合优化、姿态引导读出以及最大覆盖历史检索均有助于提升性能。

## 核心贡献

提出一种面向视频世界模型的隐式三维感知记忆机制，将历史潜在帧压缩为紧凑表示，并在固定令牌预算下进行高效写入和面向目标视角的读出。将该记忆整合到相机可控的自回归视频生成框架中，通过姿态条件读出和最大覆盖历史检索提升长时间重访一致性与相机控制准确度。通过记忆编码器、读出模块和视频 DiT 的联合优化，使记忆表示与生成器令牌空间协同适配。采用少步金字塔蒸馏和混合蒸馏模型构建实时交互系统，在 4 GPU 机器上达到 16 fps，并支持分钟级流式探索。

## 与课题的关系

与研究重点直接相关：它是用于交互式闭环模拟的动作或相机条件视频世界模型，以自回归分块方式持续生成长视频；通过隐式三维感知记忆解决跨视角、长时间重访时的场景一致性问题；通过姿态条件、近期上下文和历史记忆共同控制生成；通过少步蒸馏实现实时流式生成；通过固定令牌预算、历史帧选择和潜变量记忆编码降低长历史处理成本。其记忆编码与读出相较于基于深度估计和几何变形的空间记忆，报告了 21.7 倍的记忆处理成本降低。

## 局限 / 待核实

论文明确指出，一些特别复杂或持续时间更长的相机轨迹仍可能出现一致性失效；每个生成块都重新编码历史会产生额外延迟。作者提出未来可采用自回归流式记忆编码器，增量地将新生成块并入记忆状态，以减少对历史的重复计算。论文还显示，蒸馏版本在视觉保真度、主体跟随能力和部分相机控制指标上相较基础模型存在权衡；使用合成数据进行蒸馏可能引入纹理模糊。除此之外，论文未明确说明。
