# PlayGen2: Learning Real-Time Playable Worlds with Explicit 3D State

- **作者**：Jihai Zhang, Yuhan Zhou, Junyou Li et al.
- **方向**：World Models

## Abstract 中文翻译

构建一个可玩的世界不仅需要生成逼真的视频，还要求具备灵敏的控制、持久的空间结构，以及与动态实体之间连贯的交互。若仅将生成帧作为循环世界表示，就会把这些要求都绑定到依赖视角的外观合成上，从而难以在生成和交互过程中保持长期的空间与时间一致性。我们提出 PlayGen2，一种将学习到的三维状态演化与神经渲染分离的实时交互式世界模型。PlayGen2维护一个持久化世界记忆，其中静态几何由体素占用网格表示，玩家和其他实体则由按身份索引的三维状态表示。在固定大小的局部区域内，其世界状态模型联合学习动作条件下的实体动力学、几何补全和实体发现，并将更新提交到持久化世界记忆中。一个独立的神经渲染器根据世界状态的深度投影和语义投影合成第一人称观测，且不会将生成图像反馈给状态预测模块。我们以 Doom 为测试平台，展示了该模型能够学习包括几何感知的玩家运动以及玩家与非玩家角色交互在内的世界动力学。该框架具有较高的计算效率，在搭载 M4 Pro 芯片的 MacBook Pro 上，完整的仿真与渲染流程后端延迟约为160毫秒。除单人交互外，我们还展示了在未见过的 Doom 地图上的零样本部署、通过组合单人模型实现多人交互，以及通过基于规则的状态干预实现可编程游戏玩法。这些能力表明，所学习的游戏世界模型具有可迁移性和可扩展性。代码和预训练模型权重已公开。

## 全文总结

PlayGen2提出一种面向实时可玩世界的显式三维状态建模框架，将世界状态演化与神经视频渲染解耦。系统用持久化体素占用网格表示静态几何，用带身份索引的三维实体状态表示玩家、怪物、投射物和物品；在以玩家为中心的固定大小局部区域内，模型根据动作、历史状态和几何上下文进行几何补全、实体发现与实体动力学预测，并把结果写回世界记忆。渲染器再依据深度图、语义图、动作和RGB历史生成第一人称画面，生成画面不参与状态预测。基于约500小时、单张 Freedoom2 MAP01 游戏数据的训练，系统在Doom中实现了几何感知移动、玩家—NPC交互、长时域探索、未见地图零样本泛化、多人模型组合和规则化游戏干预。在M4 Pro笔记本上，8步去噪时串行运行约4.98 FPS、平均后端延迟200.6毫秒，重叠执行可达7.16 FPS。

## 核心贡献

1. 提出显式三维世界状态框架，将体素几何和按身份索引的动态实体状态纳入持久化世界记忆，并联合学习几何补全、实体发现和动作条件动力学。 2. 设计独立于状态预测的状态条件神经渲染器，使生成图像不会将视觉误差反馈到世界状态循环中，从而支持更稳定的长期空间与时间一致性。 3. 在Doom中实现几何感知的玩家运动、玩家—NPC交互及离屏实体持续演化，并展示十分钟级闭环探索中的控制和渲染能力。 4. 证明模型可在未见地图上零样本运行，并通过显式状态接口实现多人交互组合和无需重新训练的规则化、可编程游戏玩法。 5. 在消费级笔记本上实现完整仿真—渲染流程的交互式运行，体现显式状态建模在实时效率方面的潜力。

## 与课题的关系

与研究重点高度相关。该工作是动作条件视觉世界模型和闭环模拟的直接实例：玩家动作驱动显式三维状态转移，预测状态决定下一步局部世界和视觉观测，系统在探索中持续闭环运行。它针对视频历史作为唯一世界记忆所导致的长期空间不一致、实体漂移和误差累积问题，引入持久化世界记忆、显式几何和身份化实体状态。方法也涉及视频生成与扩散渲染：状态投影作为深度和语义条件，驱动潜空间扩散Transformer生成第一人称视频。其固定大小局部裁剪、共享上下文、RGB历史缓存以及8步去噪共同服务于实时和长视频生成；作者报告M4 Pro上串行4.98 FPS、重叠执行7.16 FPS，说明其对实时生成、缓存复用和高效推理具有明确关联。与纯像素自回归视频模型相比，状态与渲染解耦还支持离屏实体演化、多人组合和规则干预。

## 局限 / 待核实

训练数据仅来自单一Freedoom2 MAP01，且由规则控制器自动收集，规模约500小时；因此对更丰富游戏机制、真实世界和不同视觉风格的泛化仍未得到充分验证。实验主要基于Doom及七个Scythe地图，不能据此证明对一般三维环境的泛化能力。模型没有运行时碰撞校正，玩家—几何交互仍存在5.2%—6.8%的十分钟累计严重穿透率。怪物追踪成功率为200步内55%，NPC动力学并非完全可靠。未见地图上的渲染沿用了训练得到的Freedoom2风格，深度和语义条件无法提供原生纹理，因此参考指标同时受到外观差异影响。系统实时性仍有限：串行约4.98 FPS、平均后端延迟200.6毫秒，且渲染使用8步扩散去噪；重叠执行虽可达7.16 FPS，但延迟为275.7毫秒。论文未明确说明在更大规模世界、更复杂多智能体交互、更长时间跨度或真实物理规则下的表现。
