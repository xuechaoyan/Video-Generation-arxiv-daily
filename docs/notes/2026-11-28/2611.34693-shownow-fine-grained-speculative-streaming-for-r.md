# ShowNow: Fine-Grained Speculative Streaming for Responsive World Models

## Abstract 中文翻译

交互式世界模型必须在持续生成视频的同时及时响应用户动作。仅具备实时吞吐率并不能解决输入延迟问题：粗粒度生成会延迟动作更新，而输入到达后再开始生成又会增加响应路径上的工作量。我们提出 ShowNow，一种细粒度推测式流式框架，利用播放期间可用的计算资源，在输入到达前准备动作条件化的未来。单潜变量提交支持高频决策，可配置的准备机制覆盖一至八个动作。我们构建了匹配的多未来数据集，用于从同一状态训练不同的后续演化；共享历史的树执行和融合提交提高了准备效率。在单张 H100 上，我们的 5B 模型在准备八个未来时能够以 16 fps 持续生成 480p 视频。在 ViZDoom 中，与原生阻塞式 SolarWM-FT 部署相比，完整的 ShowNow 部署将输入到显示的中位延迟从 620 ms 降至 208 ms。匹配策略实验将重启阶段的空显示帧比例从 1.56% 降至 0.09%（降低 94%），并改善了动作变化时的按时响应。这些结果表明，细粒度提交与提前准备具有互补作用，同时也揭示了视觉保真度和长时一致性方面经过测量的权衡。ShowNow 将播放时计算转化为响应迅速的视觉交互。项目地址：https://github.com/showlab/ShowNow。

## 全文总结

论文提出 ShowNow，用于降低交互式世界模型中的动作响应延迟。系统在播放已生成视频时，利用空闲计算提前生成多个动作条件化的未来，并在用户输入到达后选择相应分支继续生成。其核心包括单潜变量的细粒度提交、匹配多未来数据集、共享历史的分支树注意力、缓存复用和融合提交。在 ViZDoom 上，5B 模型可在单张 H100 以 480p、16 fps 生成并准备八个未来，将输入到显示的中位延迟从 620 ms 降至 208 ms，并显著减少重启空帧和提高截止时间内的响应率。实验同时显示，细粒度自回归和部署优化会带来视觉质量及长时一致性下降。

## 核心贡献

1. 提出 ShowNow 细粒度推测式流式框架，将播放期间的计算用于提前准备动作条件化未来，并统一单未来与多未来策略，在计算开销和响应速度之间提供可配置权衡。 2. 构建并发布匹配的多未来数据集：从相同 ViZDoom 状态生成八种动作条件化后续轨迹，覆盖持续动作和动作切换。 3. 提出结合多未来训练、AnyFlow 因果蒸馏和 Self-Forcing 的训练流程，使模型能够从共享历史生成不同动作分支。 4. 设计共享历史的分支树执行、分区注意力、历史缓存和融合提交，降低多分支生成的时间与显存开销。 5. 在单张 H100 上实现 5B 模型以 480p、16 fps 准备八个未来的实时流式生成，并通过系统和匹配策略实验验证延迟、连续性及按时响应方面的收益。

## 与课题的关系

论文与研究重点高度相关。它直接研究动作条件化视觉世界模型和闭环交互仿真：用户动作选择模型预先生成的未来分支，选中的分支再作为下一轮生成的共同历史。方法属于因果、自回归和流式长视频生成范畴，通过单潜变量更新缩短决策间隔，并通过共享历史树执行、缓存复用和融合提交降低重复计算。它还利用 AnyFlow、Self-Forcing 等蒸馏方法减少采样步数，并将推测式生成、提前计算和候选分支覆盖用于实时响应。在 ViZDoom 中，系统以 16 fps 连续运行，八未来部署将中位输入到显示延迟降至 208 ms，并将重启空帧比例降至 0.09%，体现了对实时生成、动作响应和闭环模拟的直接价值。

## 局限 / 待核实

论文明确显示，ShowNow 存在视觉保真度和长时一致性权衡：ShowNow 的 LPIPS、PSNR 和 SSIM 均劣于教师或部分基线，长视频部署路径的 FD 也更高；更长的自回归历史和部署执行会进一步影响滚动质量。细粒度单潜变量提交虽然提高了短期动作切换响应，但其稳定后的动作准确率低于 SolarWM-FT。多未来准备需要额外计算资源，收益取决于输入时机、候选覆盖率、播放队列和截止时间；未覆盖的动作仍需重新生成。实验主要基于 ViZDoom、有限的八种离散动作和特定 H100/B300 部署配置，论文未明确说明其对更广泛环境、动作空间及硬件平台的泛化程度。
