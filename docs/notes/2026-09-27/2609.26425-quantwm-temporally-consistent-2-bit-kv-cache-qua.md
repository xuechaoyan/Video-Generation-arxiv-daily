# QuantWM: Temporally Consistent 2-Bit KV Cache Quantization for World Models and Video Generation

- **作者**：Jiaqi Zhao, Xiaobin Hu, Bo Yin et al.

## Abstract 中文翻译

KV 缓存内存已成为视频生成和世界模型部署中的主要瓶颈，这推动了针对高效性的低比特量化研究。现有的 2 比特 KV 缓存量化方法在 VBench 等视频基准上能够实现近乎无损的性能，但我们发现，它们仍会造成严重的时间闪烁和视觉质量下降。进一步研究表明，Key 量化产生的重建误差小于 Value 量化，但却出人意料地导致更严重的输出退化。我们将这一差异追溯到注意力机制：微小的 Key 扰动会改变注意力 logits，即 QKᵀ，并改变 Query 所选择的时空 token。基于这些观察，我们提出在 KV 缓存量化过程中显式保持注意力 logits 和时空 token 选择，以减轻视觉质量下降问题。为此，我们提出 QuantWM，一种无需训练且严格因果的 2 比特 KV 缓存量化框架。QuantWM 引入了两项互补技术来缓解注意力偏移。首先，量化敏感性感知聚类（QSAC）联合考虑历史 Query 的敏感性和残差范围，以选择适合 INT2 的 Key 聚类中心，从而减少对注意力更关键通道中的量化误差。此外，主子空间注意力补偿（PSAC）利用低秩投影，沿主导 Query 子空间恢复剩余的 Key 误差，从而直接、高效地修正注意力 logits，稳定注意力计算。在 Causal-Forcing、LingBot-World-v2、HY-World 1.5、Matrix-Game-2 和 Longcat-Video 上的大量实验表明，QuantWM 能显著提升视觉质量和时间一致性，并在图像和视频质量指标上超过现有方法，同时实现最高 6.20 倍的 KV 缓存内存压缩，仅引入有限的额外开销。

## 全文总结

论文发现，现有 2 比特 KV 缓存量化虽然在 VBench 上接近无损，却会引发视频时间闪烁、模糊和伪影，主要原因是 Key 量化扰动了注意力 logits，导致 Query 选择不同的历史时空 token。为此，QuantWM 采用 QSAC 根据 Query 通道敏感性和残差量化难度选择 Key 聚类中心，并采用 PSAC 沿主导 Query 子空间补偿剩余 Key 误差。该无需训练、严格因果的框架在五种视频生成和世界模型上降低了 token 选择偏移，改善了 PSNR、SSIM、LPIPS 及 VBench 指标，实现最高 6.20 倍缓存压缩，同时保持有限的延迟开销。

## 核心贡献

1. 揭示了 2 比特 KV 缓存量化中被视频基准忽视的时间闪烁和视觉退化问题，并证明 Key 量化比 Value 量化更敏感，关键原因是其会改变注意力 logits 和时空 token 选择。 2. 提出量化敏感性感知聚类（QSAC），利用历史 Query 的通道敏感性及残差分组动态范围，选择能减少注意力扰动的 Key 聚类中心。 3. 提出主子空间注意力补偿（PSAC），通过低秩投影沿主导 Query 方向恢复 Key 量化误差，直接稳定注意力 logits。 4. 构建无需训练且严格因果的 2 比特 KV 缓存量化框架，在多种视频生成和世界模型上实现视觉质量、时间一致性与内存效率的综合提升。

## 与课题的关系

与研究重点高度相关。QuantWM 面向自回归、因果、流式视频生成和动作条件世界模型中的 KV 缓存部署瓶颈，直接减少历史时空 token 的缓存内存。其 QSAC 和 PSAC 针对注意力选择稳定性进行优化，有助于在长序列和闭环世界模拟中维持跨帧一致性；框架采用 chunk-wise streaming 量化并仅量化一次已构建的缓存块，适合流式生成。实验覆盖 LingBot-World-v2、HY-World 1.5、Matrix-Game-2、Causal-Forcing 和 LongCat-Video，其中 Matrix-Game-2 使用动作序列条件输入。方法实现最高 6.20 倍 KV 缓存压缩，且多数模型端到端延迟增幅约 5% 至 6%，与实时生成和高效推理目标直接相关。
