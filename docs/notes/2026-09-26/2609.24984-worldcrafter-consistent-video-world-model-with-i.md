# WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

## Abstract 中文翻译

视频世界模型能够支持对动态环境的交互式探索，但在长时间范围和跨视角条件下，仍难以遵循先前的观测。我们提出WorldCrafter，一种为此目的学习可由相机查询的隐式三维感知记忆的视频世界模型。其核心思想是让请求的视角决定如何将多视角证据压缩到视频生成器有限的令牌预算中。记忆编码器和姿态条件读出模块与视频生成器联合训练，在去噪之前将历史观测整合为固定数量的、面向目标视角的令牌，且不需要基于显式深度的对应关系。结合这一记忆、近期时间上下文和少步蒸馏，WorldCrafter能够从单张输入图像或文本提示开始，以流式方式探索场景。在静态和动态场景上的实验表明，该方法显著提升了长时一致性和相机控制准确性，同时在分钟级探索过程中保持视觉质量。

## 全文总结

WorldCrafter是一种面向交互式长时视频生成的相机可控自回归视频世界模型。它从历史潜在帧及相机参数中构建隐式三维感知记忆，并通过面向未来相机轨迹的姿态引导读出，将固定数量的记忆令牌与近期上下文共同输入视频DiT。最大视场覆盖检索用于选择互补历史视图，联合优化使记忆空间适配生成器；结合少步蒸馏后，模型可实现实时流式探索。实验显示，该方法在长时重访一致性、相机控制和整体视觉质量方面优于所比较的基线，WorldCrafter-fast在4块GPU上达到16帧/秒，但复杂或极长轨迹下仍可能出现一致性崩溃。

## 核心贡献

1. 提出用于视频世界模型的隐式三维感知记忆机制，将历史潜在帧压缩为保留时空信息的紧凑表示，并在固定令牌预算下进行高效写入和读出。2. 将该记忆整合到相机可控的自回归视频生成中，通过姿态引导读出和最大视场覆盖历史检索提升长时重访一致性与相机控制准确性；相较最强基线，重访一致性提升47.6%。3. 通过少步分层蒸馏构建实时交互系统，在保持视觉质量的同时支持分钟级流式探索。4. 实验表明，WorldCrafter的记忆处理开销为每个生成块0.062秒，相比基于深度的空间记忆处理开销降低21.7倍。

## 与课题的关系

该工作直接对应视频生成与视频扩散、动作或相机条件视觉世界模型、闭环长时模拟、自回归与流式生成以及实时推理等研究方向。模型根据用户指定的相机轨迹生成后续视频块，并将生成帧加入历史档案，在重访时通过隐式三维感知记忆恢复先前场景，因此具备闭环探索能力。其记忆令牌、固定预算读出和互补视图检索缓解了全历史注意力的计算开销；少步蒸馏使WorldCrafter-fast达到16帧/秒，适合实时交互。该方法主要处理相机轨迹条件，而非一般意义上的离散动作控制。

## 局限 / 待核实

论文明确指出，沿特别复杂或特别长的轨迹进行探索时，一致性仍可能失效；每个生成块重新编码历史会带来额外延迟。论文提出未来可采用自回归流式记忆编码器，增量地将新生成块写入记忆状态，以减少对历史的重复计算。除此之外，论文未明确说明模型在更广泛动作类型、真实机器人闭环控制、极端动态场景或不同硬件上的泛化能力。
