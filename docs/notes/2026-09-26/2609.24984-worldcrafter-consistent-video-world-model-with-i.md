# WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

- **日期**：2026-09-26
- **评分**：76/100
- **作者**：Wangbo Yu, Kunhao Liu, Wenbo Hu et al.
- **方向**：World Models
- **论文**：[arXiv 2609.24984](http://arxiv.org/abs/2609.24984v1)
- **代码**：未开源

## Abstract 中文翻译

视频世界模型支持对动态环境进行交互式探索，但在长时间范围和跨视角条件下，往往难以遵循此前的观测结果。我们提出 WorldCrafter，一种为此学习可通过相机查询的、具有隐式三维感知能力记忆的视频世界模型。其核心思想是让所请求的视角决定如何将多视角证据压缩到视频生成器有限的 token 预算中。记忆编码器和姿态条件读出模块与视频生成器联合训练，在去噪前将历史观测整合为一组固定数量、面向目标视角的 token，且无需显式的基于深度的对应关系。结合这一记忆、近期时间上下文以及少步蒸馏，WorldCrafter 能够从单张输入图像或文本提示开始进行流式场景探索。在静态和动态场景上的实验表明，该方法在保持视觉质量的同时，显著提升了长时间范围的一致性和相机控制准确性，并支持持续数分钟的探索。

## 全文总结

WorldCrafter 是一个面向交互式闭环探索的自回归视频世界模型。它利用从历史潜变量帧和相机姿态中构建的隐式三维感知记忆，并通过目标相机轨迹引导读出固定数量的记忆 token，再与近期上下文共同条件化视频 DiT。模型采用最大视野覆盖的历史帧检索、记忆编码器与生成器联合优化，以及少步蒸馏，实现了较强的长时间重访一致性、相机控制和实时流式生成。在 725 条长轨迹视频上，模型优于所比较的方法；蒸馏版本可在 4 张 GPU 上达到 16 fps。

## 核心贡献

1. 提出隐式三维感知记忆机制，将历史视频潜变量帧压缩为紧凑表示，并在固定 token 预算内进行高效写入和面向目标视角的读出。2. 将该记忆整合到可控相机的自回归视频生成中，通过姿态引导读出和最大视野覆盖检索提升长时间重访一致性与相机控制精度。3. 通过记忆编码器、视频 DiT 和读出模块的联合优化，使记忆表示适配生成器的 token 空间。4. 通过混合低噪声/高噪声模型的少步蒸馏构建实时交互系统，在保持视觉质量的同时支持分钟级探索。

## 与课题的关系

论文与研究重点高度相关：它直接研究视频扩散驱动的动作/相机条件世界模型、闭环长时间模拟、自回归与流式视频生成、实时推理和缓存式历史信息复用。目标相机轨迹作为交互条件，生成视频块按序追加到历史档案中，构成闭环探索。隐式三维感知记忆将历史观测压缩为固定数量 token，避免完整历史注意力带来的成本；最大视野覆盖检索选择互补历史帧；直接在潜变量上编码记忆，记忆处理成本较基于深度的空间记忆降低 21.7 倍。少步蒸馏后模型达到 16 fps，体现了实时生成和推理加速价值。

## 局限 / 待核实

论文明确指出，特别复杂或特别长的相机轨迹仍可能出现一致性破坏；每个生成块都重新编码历史会引入额外延迟。作者提出的改进方向是采用自回归流式记忆编码器，增量地将新生成块纳入记忆状态，以减少对历史的重复计算。除此之外，论文的评测主要基于其构建的 725 条轨迹和所比较的模型，跨更广泛真实环境的泛化能力未被明确说明。
